## 实际研究

对用户指定的本地 MuffinOffice ZIP 进行只读检查；未把镜像、许可文件、私密路径或第三方原文复制进仓库。文件摘要和研究结论见 [接入研究](../../engineering/integrations/muffin-office.md)。

- 读取发行说明、PDF 能力说明、布局类型定义、示例及许可说明。
- 计算 ZIP SHA-256，逐项检查 SHA256SUMS 中 14 个文件摘要，均匹配。
- 流式读取 Docker 归档元数据，识别 Linux/amd64、镜像版本、入口、运行用户和端口；未执行归档中程序。
- 未取得独立可信签名公钥，因此未验证发行签名。摘要一致不能证明发行来源可信。
- 检查命令路径及常见安装位置，未发现 Docker CLI；没有安装、加载或启动服务，接口与往返能力均未验证。
- 查询 npm 官方注册表，Oxlint latest 为 1.93.0、Oxfmt 为 0.78.0；只记录查询结果，没有安装。

关键发现：包内只有服务端文档引擎及协议材料，没有可直接嵌入 Vue 的浏览器编辑组件；已向用户说明，保留 MuffinOffice 方向，并把组件、schema 和真实往返验证列为下一阶段门槛。
