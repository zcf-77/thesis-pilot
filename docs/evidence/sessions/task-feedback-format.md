## 实现约束与动效

- 任务和反馈写操作按项目行锁、对象版本与UUID命令幂等串行；证据是固定版本，确认复验后追加历史，不自动替换为最新版。反馈处理不连带确认任务、不生成导师认可状态。
- 格式来源合同v2保留原始v1导入骨架及精确格式覆盖；普通保存不能提交跳过保护参数。格式采纳、撤销及历史恢复使用内部guard transition，来源版本与正文同事务落库。
- 表单展开、详情/候选加载、错误恢复与列表使用共享过渡；减少动态效果时保留完整信息。取消保留本机草稿，异步旧结果不得覆盖新项目。
- 字段缺失、空列表、加载、失败、部分解析、取消编辑、陈旧依据与CAS冲突均需显式状态。导师认可不属于本轮，不能显示占位成功。
