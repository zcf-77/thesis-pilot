## 实现前任务与范围

在 apps/web 现有设计展台中增加计划、资料、导师反馈三个完整页面设计，使用既有 Vue 组件、语义令牌和四套主题。默认预览遵循朱墨建议，但不替用户最终选择主题。

对应产品 AC-003/009/016（计划与证据）、AC-013/014/019（资料与来源）、AC-004（反馈原文与拆解）。本次仅验收设计表达与页面内演示，不能算这些完整产品 AC 通过。

### 实际纠错与环境限制

1. 只读审阅发现手机顶部版本组件选择器错误（`.tp-version` / 实际 `.tp-ver`），已修复。
2. 旧证据任务原本仅显示已确认，已改为「已确认 · 需复核」；侧栏不再把 12-25 误称为最近硬截止（另有 12-22 任务）。
3. 反馈人工定位后仍显示待补充文案，已增加本人定位状态，原 AI 判断单独保留，缺证据时仍禁止标记。
4. 首次截图失败：Playwright 缺少 `chromium_headless_shell-1254`。尝试安装时实际返回 `getaddrinfo ENOTFOUND cdn.playwright.dev`，未安装成功。
5. HTTP E2E 无法继续；独立连通性检查实际返回 `connect EACCES 127.0.0.1:18745`。中止两个等待 HTTP 服务的测试进程与临时预览服务，未记作测试通过。改用本机 Chrome `157.0.8103.51` 检查可独立打开的单文件 HTML。
6. 首次离线 E2E：33 通过、1 失败。失败是新测试把 `EvidenceChip` 的展示 `span` 当作按钮查询；更正为实际证据标签并核对版本文字，单项复测 1 通过。
7. 新增测试 URL 辅助模块后，工程检查报 TS2835（NodeNext 导入缺少扩展名）；按现有配置补为 `.ts`。保留失败输出并再检查。
