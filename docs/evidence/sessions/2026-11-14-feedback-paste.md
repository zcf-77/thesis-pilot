# 导师反馈仅粘贴文字录入

- 日期：2026-11-14（Asia/Shanghai）。
- 用户原话：“只需要粘贴文字即可”。承接反馈页缺少录入入口的讨论，明确只做文字粘贴。
- 基础：沿用当前 Vue 设计展台与未提交的三页设计；既有工作区改动保留。
- 对应 AC-004 的录入与原文保留部分。完整 AI 拆解、任务关联、后端保存仍不计为通过。

## 实现前范围与验收

只在反馈页增加「录入反馈」页内表单，一个多行文本框和保存/取消动作；不用上传、OCR、资料选择或额外必填元信息。使用现有 Vue/TypeScript/TpField/TpButton 和主题令牌。仅当前页面内存保存，刷新重置，不把输入写入源码、日志或持久化。

| 编号 | 可执行检查 | 预期 |
|---|---|---|
| PASTE-01 | 展开录入、粘贴多行文字、保存 | 新记录出现并选中，原文空格和换行保留；当前筛选不会把新记录藏起来 |
| PASTE-02 | 空白提交、取消/Esc、普通回车、Ctrl/Cmd+Enter | 空白不保存；取消不增加记录；普通回车换行，组合快捷键保存且不重复新增 |
| PASTE-03 | 粘贴包含 HTML 字样的自制内容 | 作为普通文字显示，不执行；不产生虚假的导师名、反馈时间、论文版本、AI 拆解、任务或证据 |
| PASTE-04 | 检查样例与新增记录的来源/计数、刷新 | 录入时间与反馈时间区分，批次数正确；刷新后恢复样例，界面提前说明此边界 |
| PASTE-05 | 工程检查、构建、相关 E2E、截图 | 按真实结果记录；验证桌面与窄屏的输入区域和状态 |

- 录入内容没有写入持久化、源码、日志或真实模型。界面在录入前注明刷新清空；测试只使用自制文字。
