## 实现

- Vue 3 + TypeScript + daisyUI，九个组件负责顶栏、目录、工具栏、正文、AI 工作台、会话、修订审阅、评审报告与节点通知。
- Tiptap 3.33.1 的开源核心、StarterKit、TableKit 验证基础输入、选择、格式、表格与编辑事务；未采用付费扩展。
- 组合逻辑统一维护论文实例与版本；展示组件通过 props/emits 与父层交互。
- 固定样例服务从展示组件中分离，提供可替换的 AssistantService；没有真实模型或文献请求。
- localStorage 保存原型文档与章节状态；恢复或保存失败明确显示，不作为正式持久化方案。
- 修订限单段无格式纯文本；生成不写入，采纳时检查版本、原文与有限保护项。跨块/带格式/复杂对象拒绝进入小样。
- 仅评审返回明确标记的示例报告，可定位和下载，不改稿或章节完成状态。

依赖、许可及复用合同见[原型说明](https://github.com/zcf-77/thesis-pilot/blob/83b8cf4640f9744572588f10a331647f73a702f9/prototypes/workspace/README.md)。实际安装 Oxlint 1.93.0、Oxfmt 0.78.0；保存精确 package-lock.json。

## 实际问题与修正

1. 安装 `lucide-vue-next` 时 npm 提示弃用，改用 `@lucide/vue` 1.72.0；安装包声明 ISC，未误记为 MIT。
2. Vite 启动 5173 返回 `EACCES`。实际检查 Windows 端口排除范围含 5141—5240；改用 18743 后启动成功，页面实际 HTTP 200、无初次页面脚本错误。
3. 第一轮 8 项浏览器测试为 7 通过、1 失败：窄屏隐藏“辅助”按钮可见文字后失去可访问名称。添加固定 aria-label，保留原语义测试并复测。
4. 目视发现评审报告被上方空会话挤压，调整为结果展开视图；返回对话和再次查看结果都保留会话及输入草稿。
5. 首次组合读取命令在构建检查后试读尚未创建的原型 README，读取返回文件不存在；随后创建说明。此错误不是应用检查失败，最终各检查另有明确退出结果。
