# 协同任务登记模板（未认领）

由唯一协调者维护；复制后填写真实值。模板本身不代表已登记或已验收。

- task_id：TASK-日期-UUID。
- revision：从 1 开始，由协调者在每次更新时递增。
- 功能与目标：待填。
- 负责人/会话：待填。
- 协调者与唯一台账位置：待填；跨会话注明远端与分支。
- 状态：requested。
- 创建时间 / 最后更新时间 / 下次检查点：待填，含时区。
- 基础提交 base_commit：待实际读取。
- 目标版本或里程碑 target_release：待定。
- 开发分支 / worktree 绝对路径：待填。
- 关联任务 / 依赖 / 接口约定：待填。
- 需求与 AC / 工程验收：待填。
- 允许修改的精确文件或目录：待填。
- 禁止修改范围 / 非目标：待填。
- 公共文件整合者：待填。
- 数据库迁移 / 错误码预留：待核实；不存在则“不适用”。
- 开工前已有改动及归属：待核实。
- 冲突检查与认领确认：未确认。
- 认领发布结果 / 开发者获取确认：未执行；本地主会话模式注明本地。
- 验收命令、成功标准与停止条件：待填。

## 开发与交接

- 进展 / 实际修改：未开始。
- 实际检查命令、退出码、结果与日志定位：未执行。
- 失败 / 未执行项 / 已知限制：待填。
- 脱敏证据摘要位置 / 受控原始记录定位：待填，不写秘密或原文。
- result_commits：未提交。
- 下一步 / 阻塞 / 暂停原因：待填。
- 转交记录（旧 owner、新 owner、revision、旧执行者停止确认）：无。
- integration_commit / 集成后复验：未集成。
- 占用释放确认：未释放。

注意：不能预填将来的提交 SHA；本登记摘要不能替代完整开发 Prompt 链。
