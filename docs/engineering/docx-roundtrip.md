# DOCX 往返小样与支持范围

SG-02 使用本机 DOCX 解析器和 Tiptap 验证“导入 → 编辑 → 保存快照 → 重载 → 导出副本”。小样复用章节锚点、快照校验和文本补丁守卫，使用独立的编辑器检查入口。正式写作台的 DOCX 入口及完整产品验收仍待后续施工。

## 支持范围

| 对象 | 小样处理 | 实测结果 |
| --- | --- | --- |
| 标题 | 读取 Word 大纲级别、内置标题及样式继承。符合条件的单一纯文本片段可编辑，自动编号、多格式分段等复杂标题保留原结构 | 广州商学院模板识别 67 个一级至四级标题，全部锁定保留。自制样例的一级、二级标题可编辑，保存重载时章节锚点一致 |
| 表格 | 规则网格进入编辑器，符合条件的单元格文本可编辑。合并、嵌套等复杂表格以锁定占位保留 | 学校模板 6 张表的网格均可映射，65 个单元格内文本块可编辑。实际往返修改一个单元格和一个普通段落。自制合并表保持原结构 |
| 公式 | Word 公式与疑似公式文本锁定，导出沿用原 XML | 学校模板与自制样例各有一处原生 Word 公式，均原样保留 |
| 引用与 Word 域 | 文本引用、引文域、交叉引用和目录等锁定，保持原缓存和关系 | 学校模板的正文引用文本、REF 等交叉引用和目录域原样保留。自制样例覆盖方括号引用与 CITATION 域；学校模板未检出该引文域 |
| 图片与其他结构 | 图片、复杂内容和未映射对象以占位表示，导出沿用原部件 | 学校模板的 DrawingML、VML 图形、图片部件、样式、编号及关系保持原样 |

小样支持标准主文档路径和 UTF-8 Transitional DOCX。导出以同一份原件为基础，重新计算范围并比对原件指纹。文本补丁之外的结构与锁定内容发生变动时拒绝导出。文件加密、宏、数字签名或无法安全定位的包同样拒绝处理。导出只创建新文件，保留输入原件。

本轮在 Chrome 中验证中文文本输入、撤销、跨文本块补丁拒绝、保存快照和重载。中文输入测试使用浏览器文本输入，系统拼音输入法候选仍待单独检查。学校模板往返只修改 2 个 Word 文本节点，另外 62 个包部件逐字节一致。Microsoft Word 能打开导出副本，确认仍有 6 张表、1 个原生公式及原有域。封面文本增长后，Word 从 31 页重排为 32 页。后续导出须单独核对分页，目录与交叉引用是否需要更新由文档作者决定。

## 复跑方法

需要 Python 3、项目已锁定的前端依赖和 Playwright 支持的浏览器。从仓库根目录生成自制测试包并运行边界检查。

```powershell
New-Item -ItemType Directory -Path work/sg-02 -Force
python -X utf8 scripts/tests/test_docx_roundtrip.py -v
python -X utf8 scripts/tests/test_docx_roundtrip.py --fixture work/sg-02/synthetic.docx
Set-Location apps/web
$env:PLAYWRIGHT_CHANNEL = 'chrome'
vp exec node scripts/docx-roundtrip.ts ../../work/sg-02/synthetic.docx ../../work/sg-02/synthetic-run
```

替换输入参数即可验证已授权的脱敏 DOCX。输出目录须尚未存在，目录含导入会话、保存后的结构快照与 `roundtrip.docx`。会话和快照包含原文，只存于本地忽略目录。使用 Word 打开源文件副本和导出副本，检查章节层级、表格、公式、引用及页面布局。

对应 [AC-002、AC-005、AC-006 和 AC-011](../product/acceptance.md) 的前置工程证据。该小样的导出基于原件局部替换文字，正式写作支持的结构变更、自动域更新、复杂排版和 DOCX 修改说明仍待对应业务验收。
