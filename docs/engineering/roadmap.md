## 第一轮开发建议

1. 完成 [主工作区交互设计](../design/workspace-interactions.md)，在 `prototypes/workspace` 直接以 Vue 3 + TypeScript + daisyUI 可复用组件制作设计稿，样例数据及模拟服务与展示组件分离；检查论文、AI 面板、任务与差异审阅之间的操作。正式后端尚未实现，本轮 Tiptap 开源核心仅用于编辑器小样。
2. 用开源编辑内核与自有 Vue/daisyUI 外壳制作小样，验证许可、文档结构、选区、事务、撤销与保护对象，再确定具体内核。
3. 使用自制/授权样例验证标题、表格、公式、引用、图注、页码和目录及 DOCX 往返；登记可编辑、锁定、不支持范围。MuffinOffice 转换若被选用，再单独验证其服务与协议。
4. 交互确认与编辑器可行性通过后，建立正式应用最小受控修订闭环，验证正文保护和版本事务，再扩展评审与主动辅助。
5. 每项开发先绑定 AC、输入输出和可执行验收，保留真实对话与运行输出；原型验证不计为 19 项产品 AC 通过。

不将本次架构文档或发行包研究算作已完成的核心应用迭代链。技术基线见[架构说明](architecture.md)，可选转换服务的历史研究见[MuffinOffice 研究](integrations/muffin-office.md)。
