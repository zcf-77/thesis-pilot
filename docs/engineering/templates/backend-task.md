## 开工信息

| 字段 | 实际值 |
|---|---|
| task_id / title | TASK-日期-UUID / 可验证目标 |
| owner / coordinator / revision | 待填写 |
| status / confirmed_at | requested；协调者确认后才可 active |
| base_commit / branch / worktree | 实际完整 SHA 与路径；不得填猜测值 |
| target_release | 待定或已确认里程碑；不为本任务临时增加版号 |
| 产品 AC / 工程 AC / 赛事 REQ | 分别填写，工程通过不代表产品通过 |
| 允许修改路径 | 精确目录/文件；注明公共文件整合者 |
| 已有未提交改动 | 文件及归属；不能覆盖或顺手提交 |
| 上游 / 下游 | API、数据库、前端、任务消费者及协调安排 |
| 迁移父 revision / 错误码 | 集中确认；不涉及写“不适用” |

## 证据、提交与交接

- 真实用户输入与 AI 输出定位：待填；公开记录仅放脱敏摘要，原件遵循证据规范。
- 完整原始对话是否保存、位置和 SHA-256：未保存则明确写缺失，不用摘要冒充完整 Prompt 链。
- 人类决定/反馈：实际发生才填写；AI 复核不能冒称人类验收。
- 修改文件与相关文档：待填。
- result_commits：未提交；发生提交后填写实际 SHA，rebase 后同步更新。
- integration_commit：未集成；未核实不能标 integrated。
- 已通过 / 失败 / 未执行的 AC：分别列出。
- 尚未完成、风险和阻塞：待填。
- 下一个接手者的最短复现命令、环境前置和下一步：待填。
- 所有权交接与释放：协调者确认后记录新 owner/revision；不能因本轮结束自动释放。
