# 开工与收工

施工依据：[施工单](construction-orders.md)。施工范围以用户确认和 main 台账为准。2026-11-17 用户追加“以后遇到问题不要问了 按照推荐”：已确认范围内的设计与实现问题直接按推荐方案修复、验收并继续，记录纠错，不反复请示；尚未确认的施工单不因此获得授权。

## 开工

用户说“开工”或“开工 SG-编号”。AI 先读取 AGENTS、README、本流程、施工单及相关实现，执行 `git status --short --untracked-files=all`、`git branch -a -vv`、`git worktree list --porcelain`、`git rev-parse HEAD` 和 `git fetch origin`。失败须记录，不能把缓存远端状态当最新事实。

1. 只选用户已确认且依赖完成的单；未确认则列出待决问题，不施工。不指定编号时按已确认顺序选择第一张可执行单，不一次承接整个列表。
2. main 中的施工单是唯一状态权威，由一个明确的主会话协调者串行写入。不再创建 coordination 台账。多个会话先核实协调者，无法确定时停止认领。
3. 开工登记追加执行记录：负责人/会话、revision、时间、完整基础 SHA、文件范围、共享契约/迁移/错误码占用、分支或工作树、验收命令、已有改动归属。不同文件也要检查协议冲突；其他会话的改动保持原样。
4. 认领提交进入远端 main、重新获取并核实无冲突后才能编辑业务。推送被拒须重新检查全部占用；离线不新增认领。不把 Markdown 当自动锁，互斥依靠唯一协调者串行操作。
5. 小任务直接沿用合适检出；复杂且独立的任务可拆分协作，限定文件所有权，按难度选择模型和思考强度。全仓重构/迁移另请用户确认。共享文件、迁移和生成契约由整合者处理。
6. 在确认的施工单下细化“功能编号→入口→输入/操作→结果/状态→跨页→验收”，复用已有任务模板。每个里程碑、阻塞和范围变更均更新 main 状态；范围内的设计冲突按上述授权修复并验证；新增施工范围仍需明确授权。不得在分支维护另一份有效状态。

## 自动收工

2026-11-16 用户对自动收工方案答复“按此执行”：每张已确认施工单完成后，自动验收、更新 main 台账、提交并推送私有 main，不自动部署或删除分支/工作树。结合2026-11-17追加授权，失败保留现场并按推荐方案修复，未获授权的新范围另行确认。自动收工授权不代替施工单范围的确认。

每张施工单达到验收、用户说“收工”、出现无法继续的阻断时，AI 在当前会话内执行收工；不依赖定时任务。关窗口、进程崩溃或断电不能保证自动执行，下次开工必须恢复盘点。

1. 对照每项验收审查本轮 diff，执行相关真实检查。前端使用现有 check/test/build/E2E，界面变化实际操作检查；后端使用 check.py 及相关真实数据库/队列测试。纯文档运行仓库校验及 diff 检查。失败、阻断、未执行分开记录，不能标成完成。
2. 复用 `docs/evidence/sessions/` 和已有任务/会话模板记录完成内容、命令与退出结果、证据位置、遗留问题、下一步、实际提交和交付状态。不把摘要冒充完整原始对话。
3. 显式暂存本任务文件、审阅暂存差异、小步提交；按 main-workflow 集成、fetch/rebase、检查迁移和错误码与远端变化。检查通过后自动推送私有 main，无需重复询问推送许可；失败保留现场并按推荐方案修复，未获授权的新范围另行确认。不自动部署或删除分支/工作树。
4. 实现进入 main 且复验成功先标“待交付”；确认远端包含成果后，以后续台账提交登记成果 SHA 和“完成”，核实该状态提交也已推送。失败保留“待交付”与占用。证据通过提交历史定位，避免自引用提交号。
5. 本轮结束不等于施工单完成。暂停/阻塞保持占用；超时不能抢占，转交须旧会话停止或用户确认。交接写清恢复命令、未提交文件和下一步。

状态：待确认 → 已确认 → 施工中 → 待验收 → 待交付 → 完成；中途可进入阻塞/暂停，取消须用户确认并交接残留。确认记录包含用户消息日期、明确范围与决定，不能由 AI 自行补写。

## 现有工具

不新增后台服务或第二套命令系统。AI 负责执行上述步骤，现有工具承担校验：

```powershell
python -X utf8 scripts/validate_repository.py
git diff --check
```

应用命令以 [前端](../../apps/web/README.md)、[后端](../../apps/api/README.md)、[本地联调](local-runtime.md) 为准。提交复用 [main 流程](main-workflow.md)，证据复用 [证据规范](../evidence/README.md)。本文件覆盖旧协作流程中的可选台账位置与收工入口，其余所有权、事务和证据约束继续适用。
