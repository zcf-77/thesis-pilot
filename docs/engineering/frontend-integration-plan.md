# 前后端契约与首轮接入需求

日期：2026-11-14。用户在确认现有前端接入与数据规范缺口后要求“继续吧”。本轮落实公共数据规范、同契约 Mock/HTTP 服务与首批项目/诊断任务接入；不扩展论文正文写入、不改现有视觉规范、不把模拟服务称为真实后端。

## 方案与范围

统一 `src/services/`，从真实 `apps/api/openapi.json` 生成 TypeScript DTO 和运行时 schema，生成器仅支持明确的 OpenAPI 子集，遇未知结构失败。API DTO、业务关系和页面展示结构分别定义；不得将 `PreviewProject` 整包上传。

前端 `VITE_SERVICE_MODE=preview|mock|http`：默认 preview 完整保留原有本地页面；mock/http 使用相同服务接口与同一套接入页面组件，替换项目目录和诊断任务区域。每次构建/开发启动明确选择，不因网络失败退回 Mock。HTTP 使用同源开发代理；代理从仅服务端可读环境变量取得临时访问令牌，不引入 `VITE_API_TOKEN` 或浏览器持久令牌。不冒充账户登录；正式用户会话另行实现。

首轮远端项目只支持列表、新建名称、读取、改名；其元数据版本不复用正文版本。用户在项目目录明确打开某项目时，通过独立 `remoteBinding` 关联到本机工作区，保留本地 ID、正文、规划、资料、反馈和历史；不自动上传本机项目。关联包含显式服务实例标识；复制备份为新项目时移除远端关联，避免误改原项目。

任务通过新增按项目分页列表与既有创建/查询/取消接口恢复。远端任务不进入本地 `normalizeRestoredJobs`，页面离开仅取消查询，不向服务端发送业务取消；服务端返回决定最终状态。无后端支持的重试、partial、其他任务类型不伪造入口。

## 功能与验收映射

| 编号 | 入口→输入/操作→结果→关联 | 状态与验收 |
|---|---|---|
| INT-001 | OpenAPI→生成DTO/schema→公共服务→页面模型 | 生成漂移检查；未知schema拒绝；字段/空值/UUID/时间/枚举校验 |
| INT-002 | 服务工厂→preview/mock/http→明确实例与错误 | 无隐式降级；超时、取消、401、409、503与无效响应；令牌不进入客户端 |
| INT-003 | 项目页→列表/名称创建/读取/改名→服务器确认→本机工作区关联 | 空/加载/错误/取消/冲突；输入保留；旧请求不覆盖新结果；保存范围明确 |
| INT-004 | 打开接口项目→复用或新建本机关联→进入写作/任务页 | 保留本地ID与document/modules；按服务实例隔离；备份新副本去关联 |
| INT-005 | 任务页→关联项目诊断创建/分页查询/取消→状态刷新 | 创建幂等键；服务端状态真相；导航停止查询而不取消任务；迟到响应忽略 |
| INT-006 | API新增GET /jobs?project_id→分页列表→刷新恢复 | 项目存在检查、排序/分页、跨项目过滤；无迁移；同步service与HTTP回归分层 |
| INT-007 | 原有项目/任务预览→默认preview→保留完整交互 | 原页面测试/构建与类型检查；接口Mock实际浏览器验证不冒充HTTP联调 |
| INT-008 | 统一数据规范→模块字段/关系/约束→后续任务模板 | 标出已实现契约与待定领域schema，覆盖ID/归属/时间/版本/状态/错误/兼容 |

关联产品 AC-001/008/010/012/015，仅建立接入基础，不能据此将完整产品 AC 标记通过。失败不关闭表单；请求中状态通过现有 Tp 控件展示。打开/关闭表单、列表增删、错误与详情使用共享动效；减弱模式复用现有令牌，禁用旧请求和退出中的交互，不以动画延迟数据写入。
