# 论文主工作区交互设计

状态：Vue 交互原型已实现并完成限定浏览器验证，不代表正式产品功能验收。正式后端、真实模型、DOCX 保真与服务器持久化不在本轮范围。

## 目标与方向

以论文正文为主要空间，采用暖灰工作台、白色纸张、深青绿色操作重点。界面风格为设计提案，等待用户体验后调整。开源编辑内核负责文本事务与选区，Vue + daisyUI 实现项目界面；不自研输入法或光标引擎。

原型位于 `prototypes/workspace/`，所有论文、日期、评分及回复均为自制交互样例；页面明确标记原型与示例建议，无模型或文献网络请求。输入只保存在当前浏览器的原型存储中，不使用真实论文。

设计稿本身采用 Vue 3 + TypeScript + daisyUI，拆分为九个展示/编辑组件。Tiptap 编辑实例由组合逻辑统一维护，样例论文和固定回复分别放入 fixtures、services；后续继续引用 Vue 组件并替换服务，保留 props/emits 交互接口，无需从 HTML 稿重写。组件接口及启动方式见[原型说明](../../prototypes/workspace/README.md)。

## 布局

- 顶栏：项目标题、保存状态、专注写作、辅助入口。
- 左侧：论文目录与项目进度，目录点击定位章节；资料/要求为按需展开的参考信息。
- 中央：精简格式工具栏与论文正文；真正支持输入、选区、基础格式和撤销。
- 右侧：按需打开辅助侧栏；综合助手与专业分工可切换，多面板模式同时展示两个专业面板。正文编辑实例保持，不因切换重建。
- 窄屏：折叠目录，辅助区域移至正文下方，不把桌面三栏等比缩小。

## 核心状态与交互

| 场景 | 操作与反馈 | 对应 AC |
|---|---|---|
| 写作 | 编辑正文，显示浏览器保存结果；失败明确提示；专注模式收起目录和辅助区 | AC-001、AC-015 的前端局部 |
| 选区辅助 | 选择同一段落的纯文本后请求修订；固定范围、基础版本、原文和候选；拒绝跨块/复杂对象 | AC-005、AC-006 的有限样例 |
| 审阅 | 对照原文与建议，采纳才改正文；拒绝不改；正文变动后旧候选过期，允许重新选择 | AC-007、AC-008 的前端局部 |
| 撤销 | 原型内撤销最近编辑或采纳，重新记录文档版本 | AC-007 的前端局部 |
| AI 面板 | 综合、五专业分工及双面板切换，保留编辑内容、选区锚点和各面板会话 | AC-015 的前端局部 |
| 仅评审 | 从评审入口直接生成固定样例问题及参考分，定位问题，支持导出样例报告；无正文与计划写入 | AC-018 的前端局部 |
| 重要节点 | 用户确认章节完成后出现一次轻提示，可查看、稍后处理或忽略，不定时弹窗 | AC-016 的前端局部 |

## 原型验证办法

1. 实际运行构建、类型及格式检查；保留精确依赖锁。
2. 浏览器检查桌面、窄屏和多面板布局，无溢出遮挡；查看截图。
3. 自动化操作选区→生成→拒绝/采纳→撤销，断言正文变化仅在采纳后发生。
4. 生成后手动编辑正文，断言旧建议不能覆盖新稿；跨块选择拒绝生成。
5. 切换模式、关闭再打开面板，检查正文和会话保留。
6. 运行仅评审，核对正文与计划未变；标注示例评分，无真实 AI 判断声明。
7. 检查完成事件去重、忽略后不重复打扰；刷新恢复浏览器样稿。

这些结果只能说明原型交互和限定对象的小样表现，不能将完整 19 项产品 AC 标为通过。输入法实机、公式、复杂表格、分页、DOCX 往返、后端原子采纳、取消重试和真实模型均需后续独立验证。

结果区域采用可收起视图：生成候选或报告后展开占满辅助区域，返回对话后仍能重新查看结果；切换不会销毁会话或未发送草稿。2026-11-11 实际完成 Vue 类型、Oxlint、Oxfmt、生产构建及 8 项 Playwright 场景，桌面 1440×1000、窄屏 390×844 无页面水平溢出。具体失败、修正和边界见[验证记录](../evidence/sessions/2026-11-11-workspace-prototype.md)。

## 编辑内核研究

本轮用 Tiptap 的开源核心进行 Vue 接入与选区事务小样。其文档模型基于 ProseMirror，允许取得 JSON、选区和事务；可以自主实现工具栏与审阅界面。具体版本、许可和实测结果在原型说明中记录。它不是完整 Word，也不自动提供免费分页、DOCX 转换或 AI 服务。

依据：[Vue 3 接入](https://tiptap.dev/docs/editor/getting-started/install/vue3)、[文档结构与事务](https://tiptap.dev/docs/editor/core-concepts/introduction)、[开源仓库](https://github.com/ueberdosis/tiptap)、[daisyUI 与 Vite](https://daisyui.com/docs/install/vite/)。MuffinOffice 历史研究保留，后续仅按需要评估服务端转换，不阻塞此次界面设计。
