# 现有业务页自定义控件迁移

日期：2026-11-14。用户要求“永远不要用基础组件，Select框等等都不要用基础的”。本轮按浏览器默认控件外观理解并落实，复用项目统一视觉令牌与 Vue 组件；不新增页面、不改变原有业务行为。

## 功能与无损映射

| 现有入口 | 控件改动 | 保留的输入、结果与状态 | 验收 |
|---|---|---|---|
| 写作 F04/F06：助手、修订预览、导入 | `TpSelect`；自定义文件按钮 | 助手枚举、场景值、禁用和原文件校验；导入仍需显式决定 | 选择能更新对应会话；文本和不支持文件分支仍可达；键盘可操作 |
| 资料 F10—F13：分类、要求、来源、文献范围 | `TpSelect`；自定义多文件按钮 | 分类稳定ID、版本数字、来源缺失空值、停用选项和所有筛选项；原件上传不变 | 历史版仍对应原版；来源切换同时更新版本；上传文件名可见，原错误保留 |
| 计划 F07：日期、生成场景、证据 | `TpDatePicker`和`TpSelect`；统一复选样式 | ISO日期、硬截止disabled、依赖多选数组、证据和生成场景 | 日期保存/过期/依赖校验不变；清空回退逻辑保留 |
| 导师反馈 F09：定位、任务关联、正文/资料证据 | `TpSelect`；统一复选样式 | 空位置提示、章节ID/标题、任务ID、正文/资料版本数字、确认门禁 | 同名/历史来源仍精确；选择新正文版本清空旧片段；关联与解除不变 |
| 评审 F14：范围、量表、场景、问题筛选 | `TpSelect`；统一复选样式 | 全文和稳定章节ID、唯一现有量表、过滤与下载失败演示状态 | 固定输入/只读历史和不改正文保持；选项总数、文本、禁用状态不遗漏 |

## 组件契约和视觉

- 业务页不再渲染原生`select`，统一传递`options`；值保持原字符串或数字类型。`change`接选择值，只有原本读取`event.target.value`的适配函数调整入参。
- 日期控件保留ISO存储与可访问名称，弹层由公共组件绘制。原生输入仅作为文本编辑/文件选择和无障碍机制，不展示系统默认下拉菜单或文件按钮。
- 普通复选框使用共享`.tp-checkbox`外观，已有统一皮肤的复选框继续保留。文件入口由自定义label、按钮和选中文件名组成，可聚焦的透明文件input只承接系统文件选择。
- 所有标签、`aria-*`、错误、必填及禁用状态保留；公共组件负责键盘、搜索、弹层边界、主题与焦点；本分工不私造另一套颜色或圆角。

## 验证记录

本分工已迁移26个Select（写作2、资料12、计划2、反馈6、评审4）、计划3个日期控件、2个文件选择入口，并给6处裸复选框补统一样式。分类修改处理函数改接所选值，其余业务校验/存储/状态机不变。静态复核五页不再有原生`select`及日期输入。

实际执行：五页定向`vp fmt`退出0（498ms），同五页`vp lint --format unix`退出0无输出。共享组件在本分工结束时仍由其他任务实现，所以不声称全局类型或浏览器已通过；集成类型、跨页操作和视觉截图由主任务统一执行。不得把原生`selectOption`测试改为隐藏原生控件来伪装通过。

## 本轮追加：把动效接入真实功能

用户继续要求实际功能遵循全局动效规范。以下映射先于实施登记；只在变化边界使用过渡，不把整页和内部区域重复动画，不改变编辑器实例或业务数据。

| 功能入口/结果 | 动效映射 | 保留约束 |
|---|---|---|
| 写作选区气泡、范围展开、侧栏切换、消息到达、版本对比/导入预览 | 气泡`tp-pop`；展开/内容替换`tp-swap`；消息按message.id执行`tp-list` | 正文无逐字动画，Tiptap不加变化key；RevisionCard原有决定动效保持 |
| 资料上传、重命名、提取/模板/要求纠正、来源核验；新增资料、筛选列表、右侧来源版本切换 | 表单和版本详情`tp-swap`；资料/要求/文献稳定ID列表`tp-list` | 原件/历史版本不变，退出过渡结束再销毁可编辑表单；选中来源key由对象/版本组成 |
| 个人规划与任务编辑、历史展开、计划候选变化、任务新增/排序、任务证据 | 表单和详情`tp-swap`；任务/证据`tp-list`；候选区域按状态替换 | 日期/依赖校验照常；列表按任务ID重排，不使用数组序号作为动画身份 |
| 导师原话录入、理解纠正、证据选择、意见拆解和筛选、选中意见切换 | 表单/证据/详情`tp-swap`；意见和证据按ID执行`tp-list` | 保留焦点、完整原话与确认门禁；新拆解项有真实新增过渡 |
| 新建评审、运行状态、报告新增/切换、问题筛选与历史对比 | 表单/运行/详情/对比`tp-swap`；报告/问题按ID执行`tp-list` | 不改正文，不改变固定输入；原页只读抽屉沿用公共动效 |
| 五页原生details历史/依据/场景披露 | 统一`tp-disclosure`钩子接公共展开/收起实现 | 保留summary键盘语义，不为每页增加不同曲线 |

减弱动效交由共享motion.css统一取消位移并限制时长；本分工不另外声明“仅演示页有动效”。最终真实打开/关闭、列表新增和减弱动效检查由主任务执行。

### 动效落实与本分工自检

已在五页加入真实 Vue `Transition` / `TransitionGroup`，使用共用令牌和曲线。列表均按业务 ID 或固定版本号识别，并绑定 `listMotionHooks` 与 `tp-list-group`，离开时冻结尺寸和位置，避免多列退出元素拉宽。

- 写作：范围、专家导航、选区气泡、侧栏内容、双助手会话、消息、专业任务、运行/错误状态、修订历史选择、版本对比、导入预览；正文编辑器实例与 RevisionCard 原有专用动效不变。
- 资料：上传/重命名/提取纠正/模板/来源核验/要求纠正表单，资料/要求/文献及来源版本记录列表，右侧来源和版本切换，读取进度及诊断出现，来源摘录和读取记录展开。
- 计划：个人规划/任务编辑表单、校验/结果提示、生成/失败/取消、候选预览与采纳操作状态、任务时间轴及清单、计划与任务历史、选中任务详情、证据关联和归档列表。
- 反馈：粘贴录入、意见列表与详情切换、记录/理解两种状态、理解编辑、证据选项/来源摘录、证据与处理历史列表。
- 评审：运行表单、运行状态替换、报告历史、选中报告、问题筛选、历史对比、下载错误与结果通知。

新增包裹层已保留写作侧栏滚动与弹性布局、资料中屏双列详情、反馈窄屏双列意见以及计划操作区对齐；所有原生 details 加统一披露钩子，由公共层提供开合过渡。首条结果边界另有 `tp-swap`：写作两处首张修订卡与空态、首次专业任务、资料/要求从空到有结果、计划历史/证据与反馈首条证据；不依赖列表初次挂载自动产生子项 enter，也不叠加 `appear`。

实际验证：五页 SFC 模板逐个编译通过；最终定向 `vp fmt` 退出 0（406ms）；定向 `vp lint --format unix` 退出 0；`vp exec vue-tsc -b` 退出 0。静态审计确认 60 个 Transition、21 个有稳定 key 和共享离开钩子的 TransitionGroup、20 个 details 披露钩子，五页无原生 Select/日期/进度控件。未在本分工运行 build 或 E2E，浏览器视觉、真实新增/删除/筛选及减弱动效需由主任务集成复核。

边界：不为正文逐字输入、原有每个静态字段和按钮文本建立额外动画；未给无稳定 ID 的历史快照数组强加索引列表动画。这些记录所在的详情/披露区域已有打开关闭动效；不能据此宣称每个文本节点变化均有独立过渡。

集成回归修复：全量浏览器测试发现计划详情切换和评审执行状态在过渡期同时挂载新旧操作入口。五页所有同位置、带 key 的 `tp-swap` 已统一为 `mode="out-in"`，本次补齐 12 处（写作 4、资料 1、计划 4、评审 3）；反馈原有切换及两处整张 RevisionCard 已使用该模式。助手容器另由列表过渡改为按可见助手 kind 组合 key 的互斥内容切换，避免切换助手期间旧、新输入框同时可操作；内部消息、专业任务列表动效及各助手草稿保持。此后总计 61 个 Transition、20 个 TransitionGroup。纯出现/隐藏且无替代内容的过渡保持不变。该约束用于避免重复按钮、重复 region 和短暂内容重叠，未放宽测试或业务门禁。

关键操作稳定性修复：计划取消生成移入原生成按钮的固定操作槽，运行提示占预留文案行，取消按钮不参与提示位移。评审执行区保留稳定外壳，位于新建表单之前；排队/运行改为状态徽标的局部过渡，取消入口不再随状态 key 卸载重建，执行区初次出现只有透明度变化。写作会话在开始退出时立即设置 `inert` 与 `aria-hidden`，新内容进入或过渡取消时恢复，避免退出中的旧输入框接收键盘输入。未延长生成/评审定时器，未改草稿数据规则；三项失败用例交由主任务复测。
