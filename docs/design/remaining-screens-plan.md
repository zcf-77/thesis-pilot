## 共享数据与页面契约

- 统一预览状态位于 `apps/web/src/lab/state/previewWorkspace.ts`；以项目隔离模块状态，顶部、写作与报告使用同一正文版本。
- 每个模块通过 `usePreviewModule(key, factory)` 获取当前项目内状态；factory 返回可 JSON 序列化对象。不得在状态中存 DOM、定时器或 File/Blob。当前预览可保留内存，完整持久化边界须如实说明。
- 项目文稿使用 `workspace.current.document`（html/version/history）；通过 `workspace.saveDocument(html, cause)` 写入新版本；采纳前必须校验基础版本。
- 跨页用 `/screens/{today,write,plan,library,feedback,review,settings,projects,inbox,account,jobs,export}`，定位参数使用 `task` / `feedback` / `material` / `chapter`。
- 独立文件所有权：各轮拥有自己的页面、模块状态、测试与轮次文档；主代理拥有全局状态、路由、壳、共享 CSS、基础入口与汇总文档。
