# 写作工作区：按用户参考图对齐功能布局

日期：2026-11-14（Asia/Shanghai）。用户原话：“设计界面右侧的设计，我要你严格按照左边图片的功能设计来，还有进度条也要放上去”。两张用户图片分别为既有展台写作场景和当前可操作写作页。本轮以第一张的功能位置、层级和密度为准，复用当前主题；不把固定样例的完成状态或采纳结果当作实际数据。

## 实现前功能映射

| 编号 / 需求 | 入口、操作与输入 | 结果与状态、跨页关联 | 可执行验收 |
|---|---|---|---|
| WR-01 / F02、F03、F07；AC-003/016 | 全局顶栏显示项目、阶段节点与连线、提交倒计时；查看阶段 | 使用项目绑定流程快照及当前阶段；未知版本/阶段明确未知，不默认第一阶段。按真实日期计算剩余/当天/逾期，跳计划/流程查看不改变阶段 | 六节点及当前节点可见；切项目/阶段/期限随动；流程缺失不造进度 |

| WR-07 / F08 | 稿纸角标显示最近待办或截止提醒，点开对应计划 | 来自实际项目任务，不写死“周四”；无待办不显示，已完成任务不提醒 | 任务调整同步；入口跳到对应任务 |

## 布局与覆盖自查

- 取消占大幅高度的写作页展示标题，改为顶栏航线、左目录/中稿纸/右副驾；保留可访问页面标题。
- 副驾第一层为综合/专业及五助手，第二层为范围，第三层为对话和候选，输入区置底。历史、对象及完整修订表单收在次级工具，不删功能。
- 复用 `SceneShell` / `SceneWorkbench` 的既有结构、`StageRoute` / `TpSegmented` / `ContextScope` / `RevisionCard` 和令牌；替换为共享真实预览状态，不能复制展台固定数据及自动采纳动画。
- 桌面三栏优先，窄屏可切换目录/正文/副驾，入口不消失、不产生整页横向溢出。主题坞避免挡住编辑区与输入区。
- 本轮不新增网络加载、登录、后端持久化或模型调用；它们不因布局调整被记为完成。现有候选/助手的加载、失败、取消与恢复状态仍需保留。
- 前置自查：上述每项都有入口、状态来源与后续动作；完成判断和字数目标不能从截图抄录。先完成本设计再实现。
