## 数据、样式与边界

- 使用项目隔离的 `usePreviewModule('library', factory)`；只保存可 JSON 序列化状态。正文/模板/要求绑定读取统一 workspace。
- 延迟任务绑定启动项目与资料版本；取消后迟到结果不得修改页面或其他项目。
- 沿用资料两栏目录/稿纸详情、TpField/TpButton/TpTabs/TpStatus、语义令牌；统计统一 32px，间距采用规范档位；窄屏纵排。
- 导师反馈仅粘贴文字；历史图片仅为历史资料样例，不增加反馈上传/OCR。
- 当前为内存设计预览，文件大小受预览上限约束；后台解析、真实文献检索、DOCX 格式应用不伪装完成。

## 验证计划

类型检查与定向浏览器验收覆盖：真实文本上传/下载/新旧版本、提取修正、要求编辑停用及绑定、模板绑定不改正文、文献空结果/范围/多选上下文、资料解绑恢复、桌面/窄屏和原有资料场景。取消迟到与来源/版本边界由确定性逻辑及交互测试核对。

## 实际执行

- 已实现 `ScreenLibrary.vue` 四页签：项目资料、模板、论文要求、文献索引。沿用目录/稿纸两栏结构，统一统计为 32px、过滤器为 8/12px 档位、资料行为 24px；窄屏纵向阅读。
- `libraryState.ts` 使用当前项目独立状态。新空项目不复制样例资料/要求；仅文献查询保留明确标注的全局自制样例。
- 上传真实保留不超过 2 MB 的原始字节（data URL），文本真实读取；支持等待/读取/取消/失败/重试、下载原件、重命名分类、解绑/恢复、历史版本与提取修正。没有把样例 PDF/DOCX 摘录伪造成可下载原件。
- 模板结构、用途及未知项可修正成新版本，历史结构快照保留；项目可绑定具体版本。格式应用入口明确展示安全应用不支持状态，正文不变。
- 要求可从提取文本建立为待整理项，纠正、启停、查看原文/来源/历史及绑定规则集；保留各版规则快照。字数检查为明确标注范围的字符统计，其余无法确定的类型返回未知，语义要求不伪造真实 AI 结论。
- 文献查询、范围筛选、内部来源及取得内容、收藏到项目资料、多篇带入写作、引用候选交接可操作。未核实/冲突来源不能准备引用候选，未取得全文不补造页码。
- 分类选项接入配置台已启用分类，保留旧记录分类；写作读取资料名称、版本、实际内容范围与绑定要求版本。

### 集成复核纠正

主会话发现计划证据链接携带 `material` / `version`，原资料入口只读取 `material` 会误开最新版本。本轮已改为同时验证资料及版本：存在时定位指定历史文本与诊断，缺失/非法时显示「来源版本不可用」，不自动回退；用户可另行明确选择查看当前版本。历史版不显示最新版的取消状态，也不能通过历史页操作当前读取任务。新增对应浏览器用例，最终构建后验证。

新建空项目的模板/要求采用版本 0 表示尚未绑定，资料页显示「未绑定」而非伪造 v0。空规则集及没有启用条目的集合不能绑定；状态校验接受合法空库，单元用例重跑 4/4 通过（512ms）。

本轮为可操作设计预览，仍不接真实文件解析、外部文献检索或 DOCX 安全格式应用；刷新状态由全局预览边界决定。产品 AC-013/014/019 尚不因此视为正式验收通过。
