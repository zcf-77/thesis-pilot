# 统一自定义控件：功能与交互设计

日期：2026-11-14。用户输入：“永远不要用基础组价啊 Select框等等都不要用基础的 太丑了！”按当前项目上下文落实为：禁止浏览器默认控件外观，现有页面和后续开发统一复用自定义Vue控件。本轮不新增页面、不改变既有业务数据、版本及保护规则。

## 范围与设计映射

本轮实施前扫描发现44处原生Select、7处日期、2处时间、2处日期时间、4处文件输入和8处数字输入；部分复选框只有accent-color或没有样式。现有普通输入、文本域、开关、单选及滑杆已有定制样式，继续复用并检查。

| 控件 / 关联功能 | 入口与操作 | 输出及保留约束 | 状态与验收 |
|---|---|---|---|
| 自定义Select / F02—03、F06—19 | 项目、助手、证据、版本、分类、范围、规则及运行筛选；点击展开、搜索或键盘选项 | 保留每个原选项、禁用条件及字符串/数值键；先更新model再发change，原关联重置与版本逻辑照常 | 当前项勾选、禁用、空结果、清除搜索、错误；Esc取消不变值；弹层不裁切、不误关模态；四主题一致 |
| 自定义日期/时间 / F01—03、F07—08、F19 | 截止、阶段日期、计划窗口、静默时段及延后；输入ISO或选日/时刻 | 仍保存YYYY-MM-DD、HH:mm或YYYY-MM-DDTHH:mm；不改日期业务约束 | 月份切换、今天、清空、无效/越界、禁用；键盘与焦点；错误输入可纠正，不伪存成功 |
| 文件按钮 / F02、F04、F10、F20 | 论文导入、资料上传、备份恢复；自定义按钮+已选文件名 | 底层保留可访问file input及accept/multiple/change；原解析、格式拒绝、版本与恢复不变 | 文件选择和取消、错误文件、重新选择；页面无默认文件按钮 |
| 复选/单选/开关/滑杆 / 跨模块 | 上下文选择、学生核对、依赖、能力、提醒及外观 | 保留原生语义和真实checked/value/disabled，使用统一自绘皮肤 | 选中、未选、禁用、焦点；键盘Space可切换；不可用选项不能操作 |
| 普通及数字输入 / 跨模块 | 标题、正文说明、参数等 | 继续使用项目输入样式；数字保留min/max/step，隐藏默认spinner | 帮助/错误关联、placeholder、只读/禁用不丢失；可编辑、可验证 |

## 实施与自检

- Select和日历为共享Vue组件；选项数组显式传入，禁止用隐藏原生Select绕过迁移或伪造测试成功。
- 所有业务页沿用原页面与功能。页面迁移、共享组件和测试适配分工实施，避免同时覆盖文件。
- 组件交互重点验证搜索、方向键、Esc、数值类型、动态选项、模态内浮层及窄屏边缘；日历验证日期/时间边界与直接输入。
- 原有业务浏览器测试改为点击真实combobox/option，保留保护与版本断言；不能因为控件更换删去验收路径。
- 运行格式/静态/Vue类型检查、相关单元和原有全套浏览器回归；重建离线HTML，实际展开控件截图检查四主题。结果只在实际运行后登记。
