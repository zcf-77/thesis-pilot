# 现有资料页面修复设计与验收

日期：2026-11-14。用户要求修复现有设计稿，不新增页面。本轮沿用资料页四个页签与统一组件，依据 F10—F13 及审计矩阵修复以下链路。

| 功能 | 入口与操作 | 结果、状态与恢复 | 验收 |
|---|---|---|---|
| F10.01/F11.01 分类 | 上传选择配置分类 | 稳定分类 ID/业务类型与显示名分离；改名不改变模板能力，旧资料保留 | 分类改名后新上传仍可进入模板及绑定 |
| F10.02/06/07 解析与片段 | 上传→文本读取→结构化结果；查询命中片段并带入写作 | 保留原件、版本与分项未知；取消同步当前资料和版本，迟到忽略；知识上下文固定版本/位置 | 文本、空文件、未知格式、取消、重试、资料升级后旧片段可追溯 |
| F11.02/03/05/06 模板 | 模板解析、纠正所查看版本、审阅格式候选 | 从实际文本识别有限结构；未知/冲突明确；旧版纠正产生新版本；支持标题结构规范化进入写作审阅，不自动改正文 | 旧版预填正确；采纳/版本冲突/撤销由同一写作候选链验证 |
| F12.01—07 要求 | 从原文逐条提取；编辑类型/参数/来源；绑定历史集合；执行语义预览 | 硬规则按类型/参数运行，来源真实存在；冲突可产生和解除；语义模拟保存依据和输入版本，失败/取消可恢复 | 同规则不同ID同结果；引用数、字数、章节、缺来源、互斥参数；旧集合不被追改 |
| F13.04—07 文献 | 单/多篇提问、补充来源并核验、引用候选 | 所有入口核验；来源快照固定取得范围/版本；模拟核验不冒充真实出版校验；引用只追加已核实取得内容，经学生采纳 | 未核实禁提问；取消迟到不变状态；引用可采纳且原数字/引用不变 |

共享协议：分类使用 settings.categories 的 kind；citationRequest 保留 ids/baseVersion/text 并增加 sources；formatRequest 为 normalize-headings，并通过现有写作页 `intent=format` 审阅。无新增页面或路由。真实外部检索与复杂DOCX解析仍不在范围，有限结构化模拟明确标识。

## 本轮实现

- `ScreenLibrary.vue` 保留原四页签，无新增页面。上传分类用稳定ID及kind；旧名称仍可兼容，新上传模板保持业务类型。
- `libraryService.ts` 提供结构提取、带行号片段、逐条规则提取、按类型/参数检查、可解释语义预览，以及今日/写作共用的正文字数及目标。字数按非空白Unicode字符统计，排除标题/表格/图示/参考文献章节；未知/冲突参数不显示假目标。
- 解析登记统一任务，取消同步资料及当前版本/尝试结果；模板旧版纠正从所查看版本起草，新版本保留原件。模板按钮进入写作审阅标题层级/对齐，复杂格式仍明确未支持。
- 要求可修复来源版本/位置、比较历史字段并绑定历史集合；运行语义预览有依据、超时、取消、重试及旧正文提示。来源不存在或互斥参数不会标合规。
- 文献单篇、多篇和处理函数均执行核验；补充来源保存新版本并保留历史。上下文带固定版本与取得范围；引用请求带真实取得文本及来源快照，经写作专用追加候选审阅。
- 支持下载准备失败保留内容并重试；发起下载不等同用户磁盘保存成功。
