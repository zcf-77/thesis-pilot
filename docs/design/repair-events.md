# 现有页面修复：主动事件与统一执行任务

日期：2026-11-14。用户已授权修复现有设计稿，不新增页面。本轮仅在收件箱、执行任务和共享外壳内补齐功能；保持统一令牌及学生决定权。

| 功能 | 入口与输入 | 结果、状态、恢复 | 验收 |
|---|---|---|---|
| F08.01—04 | 当前项目的任务期限、确认及阶段事件；账户静默/配置提醒规则 | 同项目实际事件生成有对象与版本依据的提醒；事件身份幂等、对象级冷却；抑制记录可查，不推断线下未工作 | 不点场景按钮产生延期/确认事件；重复事件不重复，不同任务不互吞；关闭/跨午夜静默生效 |
| F08.05—07 | 收件箱查看、延后截止、忽略/恢复、线下补充 | 状态及时间即时保存，操作历史可查；无自动完成任务；L2收件箱、L3仅供今日/计划消费，不弹建议模态 | 延后后展示准确截止、恢复保留历史；补充/取消不改任务；坏深链可恢复 |
| F19.02—07 | 解析、生成、检索、评审、导出、配置发起统一任务；全局托盘 | 固定项目/范围/配置摘要；每次尝试独立保留；六状态统一筛选；托盘取消/重试回调驱动原业务，令牌拒绝迟到；刷新后不伪恢复执行 | 多来源筛选一致；取消后原业务不写结果；重试有旧诊断及新尝试；无运行时处理器时明确回来源重试 |

接口：`startProjectJob(project, spec, controls?)` 返回固定令牌句柄；`finish` 只接受当前活动令牌；`cancelPreviewJob` 更新统一状态并调用来源取消；`retryProjectJob` 调用已注册来源重试，不用假成功代替。运行时回调不序列化，快照只含必要摘要/版本。

通知时间策略：已明确的延后截止选择与展示落地，自动定时重送仍不新增；到期标明可放回待留意。现有场景入口保留为同规则测试，不代替真实事件联动。
