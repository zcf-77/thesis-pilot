## 1. 版式

| 区域 | 内容 | 尺寸与层级 |
|---|---|---|
| 左：章节目录 | 由快照章节派生的层级目录、逐章字数、全文字数与字数目标、当前章高亮；点击定位 | 200px，L1 纸面面板 |
| 中：写作台 | 文档栏 → 功能区 → 桌面（分页纸面）→ 状态栏，一个 L1 面板内自上而下 | 自适应，纸面白、桌面随主题 |
| 右：副驾坞 | `TpTabs` 动态渲染已注册面板，自带“版本”面板 | 376px，可在 320—480 间拖拽或方向键调整 |
| 浮层 | 选区气泡（L3）、冲突对话（L4） | `tp-pop` / `tp-modal` |

| 宽度 | 行为 |
|---|---|
| ≥1440 | 三栏常驻 |
| 960—1439 | 目录常驻，副驾可收起（文档栏按钮，状态记在本机）；960—1279 打开副驾时目录让位（纸面不窄于约 560px），文档栏出现“显示章节目录” |
| <960 | 目录与副驾改为覆盖式抽屉（复用 `WritingDrawer`），写作台占满宽度 |

写作台高度锁定到视口，纸面在桌面内滚动，目录与副驾各自滚动；页面本身不横向溢出。截止与阶段已在外壳顶栏（`WorkspaceProgress`）常驻，文档栏不重复。

## 2. 功能映射（功能编号 → 入口 → 操作与输入 → 结果与状态 → 跨页 → 验收）

| 编号 | 入口 | 操作与输入 | 结果与状态 | 跨页关联 | 可执行验收 |
|---|---|---|---|---|---|
| F04.01 正文编辑 | 纸面 | 输入、输入法、选区、撤销重做、加粗/斜体/下划线/上下标、段落样式（正文/标题 1—3/模型样式）、对齐、缩进、插入表格/分页符、表格增删行 | 只改支持的对象；按钮按 `can()` 与格式状态显示按下/禁用；内核无对应操作（列表、列操作、合并单元格）不显示 | — | 浏览器输入后模型文字一致；撤销重做恢复；样式与对齐落到模型 |
| F04.02 章节目录 | 左栏、窄屏“章节目录”按钮 | 点击章节 | 滚动定位并闪烁标题；当前章随光标高亮；改标题后目录随正文重算（章节 ID = 标题块 ID，稳定） | 评审/指令面板 `?chapterId=` 深链 | 插入、改名标题后目录更新且定位正确 |
| F04.03 字数 | 目录头、状态栏 | — | 全文与逐章正文字数（非空白标量、止于参考文献）；字数目标无可靠来源时显示“目标未设置”（留白），不虚构 | 今日页同口径（另切片） | 输入后字数变化；无目标不显示数字 |
| F04.04 保存与草稿 | 文档栏“保存”、Ctrl/⌘+S | 手动保存完整快照，CAS `expected_version` | 保存中/已保存 vN/有未保存修改/失败可重试；编辑即保留本机草稿（IndexedDB，按服务、项目、本地工作区、正文隔离）；刷新后单份草稿自动恢复，多份列出选择 | — | 保存后版本 +1；刷新恢复草稿；保存失败正文保留 |
| F04.04 冲突 | 保存返回 409 / 发现更新版本 | L4 冲突对话：载入最新 vN（我的版本保留为本机草稿）或先保留我的版本 | 冲突条常驻，提供“载入最新”“以我的版本保存为新版本”；后者明确说明最新版本改动不合并、可在历史找回 | — | 双窗口保存，后者得到冲突对话，草稿不丢 |
| F04.04 结果未知 | 保存时网络中断 | 检查结果 | 按提交指纹核对最新版本；一致即确认，不一致按冲突处理 | — | 单元回归覆盖 |
| F04.05 锁定 | 功能区“审阅”、选区气泡 | 锁定选区（单段内）/解除锁定 | 写入 `lock` 保护，纸面标记；随编辑移动；经手动保存生效；只能落在同一段；保护随版本保留 | 候选与评审受程序保护 | 锁定后输入被拦截并提示；保存后刷新仍锁定；解除后可编辑 |
| F04.05 保护保持 | 保存 | — | `protectionsFromRanges` 读回；有保护无法定位（lost）时拒绝保存并列出种类 | 服务端再校验 | 单元回归覆盖 lost 拒绝 |
| F04.06 对象 | 纸面 | — | 数字/引用/公式/未解析对象/原件内容按保护种类标记，修改被拦截并给出三段式原因；原件导入正文只允许改映射文字 | 原件导出由导出切片处理 | 拦截提示正确 |
| F04.07 适配 | — | — | v2 快照载入/保存、`schemaVersion` 分派、v1 只读、不能解释的快照拒绝载入并保留服务器版本 | — | 单元回归 |
| F04.08 实例保持 | 外壳 KeepAlive | 切空间再回来 | 编辑器实例、撤销栈、草稿、选区保留；回到页面时核对最新版本，不重建编辑器 | 全部空间 | 输入→切资料→回写作→撤销只撤最后一步 |
| F04.09 选区气泡 | 选中单段文字 | 请 AI 起草（打开已注册的起草面板）/锁定/解除锁定 | 气泡不改正文；Esc 关闭；跨段选区只提供解释 | 助手面板（切片 C） | 选中→气泡出现→锁定生效 |
| F05.07 版本历史 | 副驾“版本” | 版本列表、查看（只读纸面）、对比（段落级差异）、恢复为新版本 | 旧版本以 `?as=v2` 只读预览（v1 标“旧版结构转换预览”）；恢复走 `revisions.revert`（同一命令 ID 可重试），生成新版本不删历史；有未保存修改时恢复禁用并说明 | `versionRoute` 深链打开对应版本 | 对比显示差异；恢复后版本 +1 且内容等于目标 |
| 升级 | v1 正文 | 升级为新版编辑器 | 只读纸面预览 + 说明（生成新版本、保留历史、旧候选过期）；成功后进入编辑；失败三段式；本机旧编辑器草稿可下载保留 | — | v1 → 升级 → 版本 +1，可编辑 |
| 空项目 | 写作页 | 创建空白正式稿；从资料导入（导入面板注册后出现） | 空白稿直接成为 v2：创建空白 v1 后立即显式升级（后端空白稿仍是 v1，见遗留） | 资料页 | 新项目→创建→可输入 |
| F06 副驾 | 右栏标签 | 已注册面板（助手、格式、导入、导出、引用）+ 版本 | 面板拿到项目、正文版本与快照、当前选区、是否可写（无未保存修改且为最新版本）；可画叠加层、请求定位、通知新版本 | 切片 C/D/E | 注册后标签出现；`changed` 后重载正文 |
| 深链 | URL | `?chapterId=`、`?review=`+`?anchor=`、`?anchor=节点ID[@起-止]`（生成与解析统一在 `workspaceRoutes.ts`） | 滚动定位并闪烁；无法定位时轻提示说明“该位置已不在当前正文” | 评审、指令面板 | 深链打开后对应标题闪烁 |
| 结构检查 | 功能区“审阅” | 检查正文结构 | 对已保存版本发起后台任务，链接到任务详情；编辑不受影响 | 任务托盘 | 已有回归 |

明确不做：列表切换（内核恒不可用）、表格列操作与合并（内核无操作）、批注（引擎无 API）。不放占位入口。

## 3. 九种状态

| 状态 | 设计 |
|---|---|
| 空 | 空项目：`TpState empty`，“创建空白正式稿”主行动；导入面板注册后出现“从资料导入” |
| 加载 | 写作台骨架：文档栏占位 + 桌面上一张空白纸 + 忙碌提示；内核加载与正文读取分别说明 |
| 成功 | 保存后文档栏变为“已保存 · vN”，版本号 `tp-swap`；恢复/升级后轻状态说明新版本号 |
| 部分完成 | 分页后台续排时状态栏显示“排版中”；保护读回部分丢失时拒绝保存并列出 |
| 失败 | 读取失败、内核失败、保存失败、草稿写入失败：危险语气三段式 + 重试/下载草稿，不自动消失 |
| 取消 | 离开页面暂停请求；保存中离开标记结果未确认，回来后核对 |
| 过期 | 历史版本预览以旧稿材质标“只读 · vN”；面板 `eligible=false` 说明需先保存 |
| 冲突 | L4 对话 + 注意语气冲突条，选项见上 |
| 未知 | 字数目标未设置、保存结果未确认、来源保护未核对：留白语气，正文只读或不可保存并说明 |

## 4. 动效映射（§9.6）

| 触发 | 状态变化 | 动效 | 减弱模式 |
|---|---|---|---|
| 切换功能区分组、副驾面板 | 同位替换 | `tp-swap`（`panelMotionHooks`，离场 inert） | ≤120ms 淡入淡出 |
| 窄屏打开目录/副驾 | 抽屉进出 | `WritingDrawer` + `tp-drawer` | 淡入淡出 |
| 960—1439 收起/展开副驾 | 栏宽变化 | 栅格列过渡（`--tp-dur-moderate`） | 无过渡 |
| 选区气泡 | 浮层进出 | `tp-pop`，离场 inert | 淡入淡出 |
| 冲突对话 | 模态进出 | `TpDialog`（`tp-modal`） | 共享减弱规则 |
| 版本列表、草稿列表、差异列表 | 列表进出与重排 | `TransitionGroup tp-list` + 稳定 ID + `listMotionHooks` | 淡入淡出 |
| 目录点击/深链定位 | 目标荧光亮起后褪去 | 纸面 `mark` 叠加 1.4s 后移除；目录行 `tp-flash` | 叠加保留同样时长，无动画 |
| 保存状态 | 保存中 → 已保存 | `TpSaveIndicator` 内 `tp-swap` | 淡入淡出 |

动效不延迟数据生效，不重建编辑器；编辑器内部过渡在减弱模式下全部关闭（`moTheme.css`）。

## 5. 视觉

- 写作台为一个 L1 面板：文档栏（展示字体题目 + 正式稿版本 + 保存状态 + 主行动“保存”）、功能区（`TpTabs` 分组 + `tp-tool` 图标按钮 + `TpSelect` 段落样式）、桌面（`--tp-surface-sunken` 上的白纸，纸面投影用主题 `shadow-2`）、状态栏（等宽数字）。
- 一个区域只有一个主行动：文档栏“保存”是唯一 primary；“请 AI 起草”用铅笔虚线；“恢复为新版本”用印章色（学生决定）。
- 保护标记沿用保护色令牌；历史差异用 `ins/del` 令牌（事实），候选差异由面板以铅笔叠加（提议）。
- 四主题只换外壳与桌面；纸张、文字、图片保持文档颜色（暗色主题下仍是白纸）。

## 6. 接口

### 6.1 副驾面板注册表 `apps/web/src/workspace/writing/panels.ts`

接口与筛选逻辑在 `panels.ts`；协调者在同目录 `registry.ts` 的 `WRITING_PANELS` 中登记，写作页按注册表与当前文档状态动态渲染标签；没有注册的能力不出现入口。

```ts
interface WritingPanelDefinition {
  id: string;                       // 稳定 ID：assistant / format / import / export / citations …
  label: string;                    // 标签文字
  order: number;                    // 排序；内置“版本”为 90
  component: Component;             // props 见 WritingPanelProps，emits 见 WritingPanelEmits
  placement: "document" | "empty" | "always"; // 有正文 / 空项目 / 都显示
  drafts?: boolean;                 // 选区气泡“请 AI 起草”打开此面板
  emptyAction?: string;             // 空项目页的入口按钮文字（如“从资料导入”）
}
interface WritingPanelProps {
  services: BackendServices; project: ProjectRead;
  document: { id: string; version: number; snapshot: DocsSnapshot } | null;
  selection: { node: string; start: number; end: number; text: string } | null; // 折叠光标：start === end、text 为空
  eligible: boolean;
}
// emits: overlays(group, highlights) / focus(anchor) / changed() / close()
```

### 6.2 写作上下文 `useWritingContext()`（`writing/context.ts`）

面板内部深层组件可注入：`document`、`selection`、`eligible`（只读 ref）、`focus(anchor)`、`setOverlays(group, highlights)`、`clearOverlays(group?)`、`reload()`、`openPanel(id)`、`model()`（当前编辑器模型，只读）。写入一律由面板经服务端命令完成，写作页在 `changed` / `reload()` 后重载正文并清空撤销栈。

## 7. 自查

- 每条需求都有入口、后续动作、状态与恢复路径；没有假按钮或成功提示式自我说明。
- 依赖其他切片的能力（助手、格式、导入、导出、引用）通过注册表出现，未注册时不显示入口。
- 后端缺口：空白稿仍为 v1（以“空白 + 显式升级”两步实现，历史中多一条升级记录）。

## 8. 实现与验证

### 8.1 实现

- `WorkspaceWriting.vue` 编排；`writing/` 下：`docsDocument.ts`（读取、草稿、CAS 保存、冲突、结果未知核对、升级）、`docsDrafts.ts`（v2 草稿独立 IndexedDB 库）、`legacyDrafts.ts`（只读旧草稿库供下载）、`panels.ts` / `context.ts`（面板注册表与写作上下文）、`structure.ts`（目录、当前章、样式选项、锁定查找）、`versionDiff.ts`（段落级对比）、`commands.ts`（插入表格/分页符、原件只改文字的宿主否决）及六个界面组件。
- 共享改动：章节派生只保留 `services/docsContent.ts` 一份；内核资源改放 `assets/mo/pkg/`（正式服务只公开 `assets/`，原 `mo/` 在正式实例 404）；`moTheme.css` 让纸面选区文字保持文档色（全局 `::selection` 在暗色主题把文字改成浅色）。
- 实测中修正：冲突对话最初在冲突状态出现时自动弹出，载入时恢复出冲突草稿也会弹窗挡住操作，改为只回应保存；1024 宽打开副驾时纸面只剩约 300px，改为 960—1279 目录与副驾互斥；新插入表格没有边框，补网格线；暗色主题选中文字不可见；定位后编辑器的“当前项”常驻蓝底，改为只保留 1.4 秒荧光；项目向导创建的空白稿仍是旧版结构，进入写作页即升级（无内容可转换）。

### 8.3 遗留

- 后端空白稿仍为 v1，写作页以“空白 + 显式升级”两步实现，历史多一条升级记录；建议后端直接生成 v2 空白稿。
- ~~外壳顶栏 `WorkspaceProgress` 只在换页时刷新~~：整合时已接线，写作页正式稿版本变化即刷新。
- 纸面主题为内核 `minimal`，字号偏小；窄屏适应页宽时文字很小（DocsEditor 不重排），视图中可调缩放。
- 字数目标没有可靠来源，统一显示“未设置”。
