## 1. 页面开始前必须完成什么

1. **确定需求范围。** 读取产品需求及验收，逐条分解本轮涉及的 F 编号；列出已有能力、缺口、跨页依赖与明确排除项。一个功能可以跨页，一个页面也可以承担多个功能，不能用页面数量替代覆盖。
2. **先设计完整用户流程。** 写明入口、前置条件、输入、动作、输出、数据归属及版本、下一步、取消/恢复和验收。包括需要的新增、查看、修改、关联、决定与历史操作，不能停在“展示一张卡片”。
3. **补全适用状态。** 正常、首次空白、筛选无结果、等待/加载、部分完成、失败/重试、取消、未知、过期/冲突、撤销/恢复逐项判断。每个异常给出保留什么、阻止什么和如何继续；不适用须写原因，尚未实现不算不适用。
4. **逐条查漏后再布局。** 本轮范围内任一需求缺入口、后续动作、状态或验收，先补功能设计。跨页去向要对应实际设计，不用无效跳转或成功提示替代。阶段分批不能悄悄缩减完整产品范围。施工中若发现明显影响结构或操作的设计缺陷，立即停止受影响的实施并报告协调者，重新确认该施工设计后恢复。
5. **定位现有设计并接入。** 对每个受影响页面确认设计稿位置、要沿用的布局与组件，以及数据对应的状态和动作。按 [DESIGN-SPEC](../../apps/web/docs/design/DESIGN-SPEC.md#85-现有页面与业务接入) 确定默认内容和辅助入口；通用改动放共享组件或样式。
6. **实际操作后分别验收。** 交付前运行改动涉及的页面，逐页对照设计稿与同类页面，按第 5 节操作并记录差异。分别登记功能覆盖、可操作交互、视觉一致性与实际业务结果。

每次页面任务使用下表，不以空模板作为完成证据：

| 必填项 | 应写清的内容 |
|---|---|
| 来源与范围 | F 编号及具体子需求、关联 AC / M、本轮范围、依赖与排除原因 |
| 场景与入口 | 用户要完成什么、从哪里进入、已有对象还是首次使用 |
| 输入与动作 | 字段、校验、查看/新增/编辑/关联/决定、键盘操作 |
| 输出与关系 | 哪个对象变化、绑定何种版本、下一步页面及返回时保留的上下文 |
| 状态与恢复 | 适用状态、错误信息、保留的草稿/原件、重试/取消/撤销路径 |
| 统一呈现 | 设计稿位置、复用的布局及组件、默认可见信息、按需打开的入口、窄屏行为 |
| 可执行验收 | 前置样例→操作→预期数据与界面；正常、异常、边界分别检查 |
| 完成证据 | 功能设计、页面交互、Mock / 正式业务分别标注状态，附源码、测试或截图 |

## 3. 当前三页的功能流程设计

下面保留规范补充轮定义的目标行为和跨页关系。**本轮已实现范围以第 4 节为准，受限能力不因目标流程写在这里就算完成。** 具体实现前的输入、状态、验收与自检分别记录在 [计划轮](round-plan.md)、[反馈轮](round-feedback.md)、[资料轮](round-library.md)，不据此宣告 D01 或 M02 全量通过。

### 3.1 计划：从任务到证据和确认

- **首次进入：**提供填写个人规划与暂不规划两种路径。无规划仍可根据阶段、硬截止和任务使用系统，不能编造个人效率；有规划可查看和调整个人约束。
- **任务管理：**从任务列表新增，详情原地编辑目标、验收条件、期限、前后置依赖和关联章节。排序与依赖分别处理，保存前检查依赖环、前后置日期与硬截止；错误定位到冲突任务，保留未保存输入，Esc 取消修改。
- **证据与状态：**从任务详情选择实际章节/产物的具体版本，展示证据来源与缺项。学生执行完成确认后，保存确认记录并更新派生进度；不能凭 AI 或文件存在自动确认。返工保留原因和原确认记录；替换证据或正文更新保留旧关联并标为需复核，可查看版本差异、补充证据并重新确认。
- **计划建议：**查看触发原因、影响任务及前后差异，再选择采纳或保留原计划；采纳时重新检查基础计划版本与约束。循环、冲突或无可行方案显示具体原因和调整约束入口，不移动硬截止。过期候选重新生成/审阅，取消和失败保留原计划，撤销可追溯。
- **跨页：**证据跳到资料或写作的对应版本，反馈任务回到原文；返回保留筛选与选中任务。确认完成、学生处理反馈和论文质量互不替代。

### 3.2 反馈：从原文到学生处理

- **录入：**「录入反馈」展开单个多行框，粘贴→保存/取消。保留原始字符、换行、来源和录入时间；未知导师姓名、反馈时间与论文版本保持未知。Enter 换行、Ctrl/Cmd+Enter 保存、Esc 取消；空白及超限不提交，取消保留草稿。不得增加额外必填字段、文件上传或截图识别。
- **拆解：**保存后在所选原文旁提供拆解动作，明确使用的论文上下文。等待/处理中可取消；失败可重试，原文始终保留。结果逐项对应原文范围，标记歧义、定位失败和材料不足；Mock 必须明确说明是模拟结果，不能给任意新文本套用现有固定拆解。
- **纠正与关联：**学生可原地修正解释、章节定位和任务内容，Esc 取消编辑；原文保持独立。选择已有任务或审阅并采纳创建任务建议，再关联实际修改、正文版本及证据。生成建议、录入原文和点击关联都不自动宣告任务完成。
- **处理与历史：**查看关联证据后标记「学生已处理」，保留动作、时间、对应版本及撤销记录。正文或证据版本变化时保留旧处理依据并提示复核；回到原文可看全过程。没有教师审批入口，不产生「导师已认可」。
- **跨页：**任务打开计划对应项，修改打开写作版本/差异，证据打开资料来源；返回保持原文和选中拆解项。拆解取消后迟到结果不得创建任务或改变处理状态。

### 3.3 资料：从原件到模板、要求及引用

- **文件：**上传后直接保存原件并进入解析，选择项目与分类；详情包含来源、类型、版本及处理状态。查看/下载原件、整理、关联、解除关联与文件移除各有明确语义，历史报告的来源仍可追溯。首次空白给上传入口，筛选空结果给清除条件；重复上传可追溯，更新产生新版本。
- **解析与知识：**等待、处理中、成功、部分成功及失败分别显示；失败保留原件并可重试，部分结果列出未识别项并可补充。提取结果可回到原始位置，纠正产生新版本；知识检索结果绑定来源文件版本，不把未解析内容显示成已知结论。取消后迟到结果不替代现有版本。
- **模板：**展示名称、用途、来源、版本、解析状态与支持范围；逐项查看结构/格式、未知/冲突并纠正生成新版本。项目选择具体模板版本；应用既有正文格式走候选审阅与采纳。解析、编辑、导出能力分别说明，不设计更新影响评估。
- **论文要求：**按范围、类型、状态筛选；详情包含原文位置、来源版本、参数、严格程度、可自动判定性与不确定性。编辑/停用保留原值和版本记录，项目及评审绑定明确版本。硬规则由代码检查，语义判断附依据；缺失或矛盾时显示不能判定，上传资料不改正文。
- **文献：**关键词查询→筛选→详情和实际来源→保存至项目资料→单篇/多篇加入助手上下文→生成引用候选→学生审阅。明确题录、摘要、全文的实际取得范围；无结果、来源不可用、全文不可访问、题录冲突与无法核实分别给出继续路径。未取得全文不得补造页码或研究结论。
- **跨页：**模板/要求绑定状态在写作与评审中一致；综合及五类专业助手共用项目绑定的同一组适用要求，调用明确所用版本，提示词或资料中的指令不能绕过确定性硬规则。文献仅将用户选中的版本传给助手，引用修改进入 F05，不直接插入正文。文件管理与导师反馈的文字录入保持各自入口。

## 5. 全局风格检查

页面外壳统一使用 [PageScreens.vue](../../apps/web/src/lab/pages/PageScreens.vue) 与 [screens.css](../../apps/web/src/lab/screens/screens.css)，基础动作、字段和状态复用现有 `Tp*` 组件；字号、间距、颜色、圆角、投影、动效以 DESIGN-SPEC 和令牌为准。四个现有主题是同一系统的取值，不能让不同页面各选不同主题。

| 检查维度 | 交付前核对 |
|---|---|
| 信息层级 | 逐页对照稿件，先确认进入时能识别当前任务及下一步，再打开详情检查辅助信息；同类页面的页头、列表、表单、空态用同一层级和间距 |
| 颜色和材质 | 原始事实用墨、AI 候选用铅笔、学生决定用印章、未知用留白、旧结果用过期语义；状态不能仅靠颜色 |
| 通用组件 | 实际操作页面的主次按钮、表单、空态和详情，核对按钮、字段/错误、加载和浮层在同类页面中的呈现 |
| 交互 | 用指针和键盘切换选项，核对选中态、点击边界和行内动作；单行编辑 Enter 保存 / Esc 取消，多行 Enter 换行，明确保存快捷键，退出后焦点返回触发处 |
| 响应式与主题 | 同主题横向对照页面；验证四主题的语义和对比度，桌面/窄屏布局、长文本、空态及减弱动效 |

2026-11-14 规范补充轮发现的三项偏差，本轮处理如下：

| 原发现 | 本轮实际处理 |
|---|---|
| 资料页统计 28px，与计划/反馈 32px 不一致 | 资料统计已统一为 32px，保持同层级字阶 |
| 资料过滤器 `6px 10px`、行内 `22px 24px` 不在规范档位 | 已改为 `8px 12px` 与 `24px`，沿用规范间距 |
| 历史图片样例可能被误解为反馈上传入口 | 页面明确标注历史资料、无原件/OCR；反馈入口仍只粘贴文字，未新增上传能力 |

以上是具体修复事实，不代表完成所有主题、状态和屏幕尺寸的视觉验收。各轮已有的截图/浏览器范围见对应轮次记录；最终桌面对照、代表页四主题及三种宽度回归见[集成记录](../evidence/sessions/2026-11-14-complete-designs.md)。集成检查另修正了公共入口复选框和三主题下拉箭头的共享样式。
