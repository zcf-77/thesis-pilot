# 现有页面实际动效接入

日期：2026-11-14。用户原话：“全局所有地方都要采用该有的动态效果。不要动态效果页面规定了，但是具体实现的时候新增等直接冒出来。”

## 范围与功能约束

仅修复已有十二个Vue页面及共用组件、展台控件，不增加页面。沿用 [设计规范](../../apps/web/docs/design/DESIGN-SPEC.md) §9，复用四主题令牌。以下为实施前的交互映射；是否验证通过以本轮证据记录为准。

| 功能范围 | 触发与结果 | 动效与恢复 | 验收 |
|---|---|---|---|
| F01/F02 项目、账户 | 新建/归档/恢复项目；修改与保存偏好 | 表单tp-swap，卡片tp-list，反馈淡入 | 新卡有真实进场；取消不新增；切换不丢草稿 |
| F03/F07 今日、计划 | 新增任务、筛选、任务详情、阶段推进 | 列表进出重排、详情替换、既有进度过渡 | 稳定ID；退出不拦截点击；进度来自状态 |
| F04/F05 写作 | 切换章节、生成修订、采纳/拒绝/撤销 | 目录列表、候选内容替换、落墨/钤印与状态过渡 | 编辑器和选区保留；不因动画重复采纳 |
| F06 副驾 | 消息新增、切换助手、展开选区操作 | 消息列表与浮层过渡 | 草稿保留；浮层离场不可点击 |
| F08 收件箱 | 筛选、稍后提醒、忽略/恢复 | 列表进出重排、详情替换 | 新增与恢复均有进场，状态即时更新 |
| F09 反馈 | 粘贴文字表单、保存、拆解、处理/撤销 | 表单、反馈列表、拆解结果和选中详情过渡 | 只粘贴文字；原文和未提交草稿不丢失 |
| F10–F13 资料 | 上传/录入、筛选、选中详情、要求/文献 | 表单、列表与详情过渡 | 保留文件与版本；错误可重试 |
| F14 评审 | 配置、生成报告、切换历史、问题操作 | 配置、报告、历史列表过渡 | 不假装检查成功；未检查项仍可见 |
| F15–F18 配置 | 编辑模型/流程/提示词、关联与版本 | 表单和列表过渡；自定义Select | 关联值和数值类型不变；禁用仍有效 |
| F19 后台任务 | 托盘、任务新增/完成/取消、详情 | 托盘tp-pop、任务列表/详情tp-swap | 进度不伪造；取消后迟到结果不回写 |
| F20 导出备份 | 选格式、导出执行、完成/失败与历史 | 状态和列表过渡 | 已支持格式可下载；未支持仍失败 |
| 全局导航/浮层 | 页面、下拉、日历、折叠说明、外观坞 | tp-page、主题浮层、disclosure、tp-dock | KeepAlive保留状态；快速重开不被旧动画关闭 |

## 实现要求

- 条件内容必须接入Vue Transition；动态集合接入TransitionGroup，使用稳定业务ID，不用数组下标或随机key。
- 多列列表离场由 `src/design/motion.ts` 保存真实宽高和坐标，防止卡片离场撑满整行；离场元素立即变为inert并退出无障碍树。
- 下拉与日历使用原地DOM的Popover顶层，保留主题和所属模态；开关有实际动画，关闭同步停止交互，动画结束后隐藏。旧回调不能影响新一轮展开。
- 动画不参与业务提交时机，不延迟保存、采纳或取消；不得通过重建Tiptap来触发动画。
- 普通内容不反复播放钤印；已有决定签名只在对应状态变化时播放。
- 完整模式读取统一主题令牌；减弱模式保留信息，以100ms淡入淡出替代位移/缩放/弹跳，退出和新增同样适用。模态定位保持不变。

## 验证方式

静态类型/构建与原有业务回归继续运行；新增浏览器用例操作真实项目创建表单、新卡片、下拉与日历，通过 `getAnimations()` 检查实际运行的透明度动画及减弱模式时长。检查四主题与390px浮层边界、键盘选择、禁用项、取消与焦点返回。最终导出HTML必须重建后复测，不能复用旧文件。

## 正式稿及写作抽屉补充

| 触发操作 | 状态与实际动效 | 减弱模式及实测 |
|---|---|---|
| 正式稿生成、决定、采纳、撤销与恢复 | 复用共享修订卡、检查展开、状态过渡与版本时间线；服务端事实生效不等动画，编辑器保持同一实例 | 主代理真实 HTTP 检查生成/决定不改稿及采纳/撤销/恢复各自追加版本 |
| 窄屏打开/关闭章节目录或副驾 | 原地模态顶层、主题遮罩、tp-drawer 进入/退出；退出立即 inert，快速重开隔离旧回调，结束返回原入口焦点 | 两类抽屉实测 100ms 透明度变化，逐帧位置不变、transform 为 none；四主题窄屏行为回归通过 |

实施与真实纠错、检查、交付文件记录见[本轮证据](../evidence/sessions/2026-11-14-custom-controls-motion.md)。运行中的取消入口保留稳定位置与可交互外壳，仅状态说明做局部过渡；不能为“加动效”让按钮反复卸载、移动到固定顶栏下，或阻止及时取消。会话退出立即停止交互，输入绑定目标助手而不是退出中的旧区域。
