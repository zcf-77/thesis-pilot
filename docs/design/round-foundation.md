# 基础入口轮：功能设计与验收

日期：2026-11-14（Asia/Shanghai）。范围 F01/F02/F03/F08/F19/F20，关联 AC-001/010/012/016。用户要求完整实现剩余设计稿，每轮遵循规范并自检。

## 实现前设计

| 入口 | 输入与操作 | 输出、关联及状态/恢复 |
|---|---|---|
| 今日 | 当前项目、任务、阶段；查看近期任务、阶段缺项、继续写作 | 跳转对应任务/文稿/反馈/评审；首次空项目引导设置，进度仅依据学生确认 |
| 项目 | 新建/编辑题目、期限、阶段、规划可跳过、版本绑定；空白或文本导入 | 项目独立ID/正文/模块状态；切换隔离，归档可恢复；空题/非法日期/不支持DOCX导入明确失败且旧稿不变 |
| 账户 | 昵称、主动建议开关、静默时段、进入/退出/失效 | 页面偏好即时更新；会话失效保留当前内存正文，可重新进入或下载备份；不实现真实认证 |
| 收件箱 | 分类、未读/延后/忽略、原因/依据、补充线下进展 | 只更新建议状态及记录，不确认任务；关闭/静默抑制模拟主动通知，同一事件去重；无结果可清筛选 |
| 执行任务 | 状态筛选、选择任务、取消/重试、诊断与输入快照 | 明确模拟执行；取消抑制迟到结果、重试保留次数和原因；不假装调用解析/AI服务 |
| 导出备份 | 选择HTML/纯文本、完整预览JSON备份，选择备份文件检查后恢复 | 真实可打开下载；损坏/未知结构拒绝且当前项目不变；恢复新增项目不覆盖现有内容；DOCX/PDF显示当前不支持并提供实际格式 |

共享状态使用项目ID隔离各模块，所有正文变更产生版本；备份只保存可序列化预览数据，不含任何密钥。刷新内存清空须在外壳明确提示；下载备份与恢复是本轮数据续用方式，不宣称自动持久化。

布局复用七空间导航轨、统一页头、纸面卡片及Tp组件，附属入口放顶栏；手机导航局部横向滚动，页面不得整体溢出。四主题只使用统一语义令牌。

## 可执行验收

1. 新建空项目→输入正文→切换原项目→返回新项目，正文与任务/反馈不串用；归档/恢复可用。
2. 退出/模拟失效后正文仍在，重新进入可继续编辑。
3. 建议延后/忽略/恢复、补充线下进展均有实际状态，事件重复触发不重复插入。
4. 取消运行任务后等待原完成时刻，仍取消；重试更新次数且可再次失败或完成。
5. 导出文件读取内容与当前项目一致；备份恢复到新项目；损坏备份不改变项目列表/正文。
6. 所有路由桌面/窄屏无横向页面溢出，切换四主题不改变业务状态；共享字号与间距一致。
