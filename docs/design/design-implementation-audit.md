## 6. 设计差异和未确认项

1. 原稿三种外壳是备选，当前用户要求对齐第一张写作图功能；不要求三套同时实现。专注模式、航图首页是建议，单列而不冒充硬性漏项。
2. 四种进度分别为流程位置、阶段已用时间、已确认任务、字数目标；倒计时不能替代时间比例，字数不能代表任务完成或质量。
3. 文献原稿禁止未核实来源用于提问或引用。现有较宽入口是明确差异；若要允许“对未核实题录提出核验问题”，需要后续明确例外范围，不能静默放宽。
4. 原稿已设计延后截止选择/展示，这是漏项；是否在指定时刻自动重新送达的调度细则尚未明确，单独保留，不假定已批准自动提醒机制。
5. 稿纸便签保留轻量提醒意图；用户未要求复制固定“周四”日期。应取实际任务，并遵守稿纸L1上限与不打断约束。
6. 真实复杂DOCX/PDF转换可不接；但安全格式候选、解析/失败模拟、引用采纳等明确Mock交互仍需实现。新增对象、完整JSON Schema引擎、字典全历史等额外建议不计作本轮确定漏项。
