# 写作空间：功能设计与本轮自检

日期：2026-11-14（Asia/Shanghai）。范围 F04/F05/F06；关联 AC-002/005/006/007/008/010/015。输入为用户继续完成全部设计稿的要求，不接入真实模型、DOCX 转换或后台。

## 页面实现前的功能设计

| 需求 | 入口、输入、操作与结果 | 状态、恢复、跨页和验收 |
|---|---|---|
| F04 文稿 | 写作导航进入同一项目正文；Tiptap 输入、标题、列表、表格、撤销重做；目录定位，选区和字数；内存保存版本 | 空正文能编辑；手动保存和采纳分开；从其它页返回保留正文；无法安全导入的 DOCX/图片/公式等明确限制并保留现有正文 |
| F04 保护 | 选中文字→锁定给 AI；数字与引用自动识别；手动编辑允许修改本人内容 | AI 选区涉及锁定/公式/复杂对象则拒绝；不能把视觉下划线当校验；保护状态和不支持原因可见 |
| F05 候选 | 选区→目标/替代文本→生成预览候选→逐段接受/拒绝→采纳所选→新正文版本 | 生成不改正文；程序核对数字、引用、公式、锁定、范围、重叠和基础版本；过期重新生成；取消抑制迟到结果；撤销仅在采纳后无新编辑时直接执行，否则走历史对比 |
| F05 历史 | 查看各版本→原文/当前对比→恢复所选版本形成新版本 | 不删除历史；恢复前可见差异；旧候选不能覆盖新版本；所有内容均当作数据渲染 |
| F06 助手 | 综合/五专业助手，单/双面板；独立输入草稿/会话；显示项目、正文、规则版本、选区和所选资料 | 发送模拟说明/建议，不宣称真实推理；等待、失败重试、取消；切换保留草稿，项目隔离；专业入口链接资料/计划/评审 |
| 相关对象 | 资料通过 materials/intent=citation 跳入；反馈与评审通过 chapter 定位；导入入口可接纯文本 | 引用建议仍是候选；仅取得题录/摘要时不声称全文；不把任意用户文本套用固定论文结果 |

## 统一呈现

复用共享页面外壳、TpButton/TpField/TpTabs/ContextScope/RevisionCard/VersionTimeline 等组件，左目录—中央稿纸—右副驾。正文纸面、候选铅笔、学生决定印章、未知留白；四主题仅消费语义令牌。窄屏变为纵向编辑/助手，工具栏允许局部换行，不缩放稿纸。Enter 依据控件语义，修改表单 Esc 取消。

## 可执行验收

- 选择实际段落文字→创建候选，检查正文及版本未变；选择片段再采纳，新版本只包含采纳文字；撤销恢复对应内容且追加历史。
- 编辑正文后旧候选过期；数字、引用、公式或锁定违规候选不可采纳；越界与重叠补丁在确定性单测中拒绝。
- 两助手分别保存草稿；发送后取消，等待结束无迟到回复；失败后可重试；离开再进入正文保留。
- 浏览器真实输入与工具栏操作、版本比较恢复、纯文本导入；无法处理的文档不覆盖当前正文。
- 桌面/窄屏和四主题查看，运行 vue-tsc、相关单元/E2E 并记录实际结果。

## 实现与验证结果

### 本轮已实现

- 新建 `ScreenWrite.vue`：共享项目正文的真实 Tiptap 编辑、章节目录、字数与内存版本，标题/列表/基础表格、撤销重做、纯文本导入与历史比较恢复。
- 复用候选审阅组件，对实际同一文本块的选区生成确定性预览；逐片段接受/拒绝后才采纳。生成、取消、校验失败、过期、已采纳、拒绝与撤销均有可操作状态。
- 新建 `writingGuards.ts`：检查数字（包括科学计数法、全角数字）、引用、公式、AI 锁定、原选区、原文字面、基础版本与补丁重叠；任一失败或不支持阻止应用。数字/引用的视觉下划线与真正程序校验分开。
- 六个助手分别保存消息和草稿，可同时打开两个；上下文显示真实项目、文稿/要求版本及资料名称/取得范围，支持取消及失败重试。回复明确为预览，不调用模型。
- `writingState.ts` 声明项目内 `writing` 状态及完整结构校验供备份恢复；重新进入时不恢复悬挂运行，正文变化令旧候选过期。
- 资料引用草稿、评审修改目标、章节定位和旧版本证据均有跳入处理；旧版本只打开对比，未找到快照明确提示，不覆盖当前正文。

### 追加复核修正

- 主会话发现真正的保护缺口：原先只比较补丁内部数字/引用，选区切开完整对象时可能漏判，例如 `引用[1]` 仅选择 `]` 改为 `）`，或 `1200` 仅选择 `20` 改为 `20万`。已改为必须提供完整文本块上下文：先检查完整保护对象的边界，再对接受片段的最终组合重新提取比较数字与引用。公式依据整个文本块保守拒绝，不能只选择变量绕开等号检查。
- 新增确定性回归覆盖上述两例、中文引用部分选取、百分数小数点、删除普通文字造成邻接数字合并、公式变量及合法局部表达。11 项单元测试通过；第 6 项浏览器测试在最终构建上定向复测通过（`--grep '切开引用'`，1 passed，5.5s）。该测试先断言实际 DOM Range 选中文字及页面选区长度，再确认候选产生、数字/引用校验失败、接受按钮禁用且正文不变。
- 第 6 项浏览器测试最初采用连续键盘定位，实际失败页面显示「尚未选择文字」，未进入候选校验。测试改为使用浏览器 DOM Range 对真实文本节点选择，处理数字/引用装饰分开的文本节点；不访问 Vue 内部状态，也未改动应用保护规则。定向复测产物为 `apps/web/test-results/write-boundary-fix`。
- 新项目的模板/要求版本 `0` 统一显示「未绑定」，上下文与候选依据明确尚不能判断论文规范；选区和内容保护依然生效。`writing` 状态校验不要求模板绑定，不伪造缺失规范。

### 已知边界

状态仅存在当前预览与用户主动下载的项目备份，刷新不会从服务端恢复。仅同一文本块、相同格式的纯文本选区支持候选应用；跨段/跨表格单元格、混合格式、公式和复杂对象明确拒绝。图片、页眉页脚、真实分页和 DOCX/PDF 转换不冒充已实现；可在资料页保留原件。助手为明确标注的行为预览，不提供真实语言模型判断。这些结果不等于完整产品 AC-002/005–008/010/015 已通过。
