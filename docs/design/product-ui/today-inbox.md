# 今日与收件箱：产品级界面收敛

日期：2026-11-19。施工单：W-E。范围仅限 `apps/web/src/workspace/today/**`、`apps/web/src/workspace/inbox/**` 及必要的专属测试。依据为 F02、F03、F07、F08，关联 AC-001、AC-003、AC-009、AC-016；本轮是既有正式页面的信息层级与交互优化，不改服务契约，不据此宣告产品 AC 通过。

## 1. 设计决定

- **今日先回答三个问题**：现在处于哪个阶段、最紧要的任务是什么、哪些事项等我决定。项目题目、阶段、真实任务数、正文字数和日期是首屏主角，不再使用宣传式导语填充空间。
- **通知先指向对象与行动**：列表保留全部已加载通知。每条通知的桌面布局为“对象与原因／状态与下一步”双栏，窄屏按同一阅读顺序堆叠；依据、不确定性和操作补充仍完整保留。
- **少一层容器**：页面只保留任务、决定、阶段确认、通知这些业务对象的纸面边界。统计、说明、进展记录用分隔线、字重和留白组织，不再把说明文字做成卡片中的卡片。
- **不另造主题**：仅消费现有 `--tp-*` 语义令牌、`Tp*` 组件与 `screens.css` 公共布局。状态文本使用对应 `-content`；学生确认继续使用印章，系统通知不冒用学生决定材质。
- **动效解释实际变化**：列表进出、详情/表单替换复用 `tp-list` / `tp-swap`；退出区域立即 `inert`，快速关闭再打开时旧聚焦回调不能影响新表单。减弱模式沿用全局不超过 120ms 的透明度过渡。
