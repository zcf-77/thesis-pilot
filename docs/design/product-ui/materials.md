# 资料、模板、要求与文献：功能及动效映射

日期：2026-11-19。施工单：W-E。基线：`923336a`。

## 1. 来源、范围与实际接口

- 来源：F10、F11、F12、F13，AC-002、AC-013、AC-014、AC-019，以及 `DESIGN-SPEC`、`page-functional-design.md`、`global-motion-implementation.md`。
- 范围：正式资料页的原件清单、上传与下载、分类与项目关联、解析任务、原件／解析版本、模板与要求集绑定、文献检索与保存、条目核验、移除恢复及助手上下文交接。
- 现有真实能力：`MaterialService` 提供有界原件上传、原件读取与校验下载、元数据 CAS 修改、不可变原件／解析版本、重新解析、固定来源绑定及绑定历史；`Job` 提供排队、执行、取消、失败与幂等重试；`LiteratureService` 提供固定检索快照、公开来源检索、保存、DOI 回查、移除／恢复与条目历史。
- 状态约束：所有成功、进度、取消与绑定版本均来自服务响应；请求按项目、资料和原件隔离，迟到响应不得覆盖新对象。资料上传、模板／要求绑定、文献保存及加入上下文都不直接改写正文。
- 本轮只调整指定页面组件、呈现辅助函数和专属回归，不改共享组件、服务、生成契约或后端。现有契约没有解析项／要求条目的纠正、启停写入接口，不新增无效按钮；AC-002 的正式 DOCX 章节导入仍属写作页，本页只保证资料原件、解析诊断与来源可追溯。
- “完成”仅指本轮页面显示、交互和实际执行的工程检查，不据此宣告 AC-002、AC-013、AC-014、AC-019 的完整产品场景通过。

## 2. 统一呈现决定

1. 页头只保留“项目资料”和上传主行动，删除宣传式眉题、重复口号和大统计。首层按“分类／检索 → 对象清单 → 选中对象 → 来源与下一步”组织。
2. 桌面采用主从双栏，清单宽度受控，选中对象获得主要阅读空间；不超过 1050px 时仍保留清单，选择后用 `TpDrawer` 打开同一详情，关闭返回触发项。390px 不出现横向页面滚动。
3. 清单行优先显示名称、分类、格式、当前原件版本和真实解析状态；版本总数、移除／解绑等次要事实降级。长名称和长文件名完整换行，不以截断改变对象身份。
4. 选中详情只保留一个纸面层。对象摘要、解析操作、版本记录、整理关联和提取结果以分隔线分区，不再卡片套卡片。重命名与来源编辑支持 Enter 保存、Esc 取消，也提供指针可操作的保存／取消按钮。
5. 原件 SHA-256、响应摘要、任务错误码和完整诊断只进入版本／来源／解析详情。主界面保留用户判断所需的状态、限制与恢复动作。
6. 模板显示具体解析项、未知／冲突和固定版本绑定；要求页先选择固定解析版本，再保存项目要求集。写作、助手与评审共用的绑定事实只说明一次。
7. 文献行直接显示实际来源及取得范围；详情区分题录、摘要、全文和核验状态。保存、打开来源、重新核验、加入助手上下文与前往写作是明确的下一步，未取得的全文、页码和结论不被补造。
8. 首次空白、筛选无结果、列表读取失败、部分信息失败、上传结果未知、解析失败／取消、检索失败／无结果和绑定冲突分别保留原数据与恢复路径，不用说明文案替代实际状态。

## 3. 功能映射

| 功能 | 入口、输入与动作 | 结果、跨页关联与状态恢复 | 可执行验收 |
| --- | --- | --- | --- |
| F10.01 上传与分类 | “上传资料”；选择 DOCX、TXT／MD／PDF，填写分类、名称与来源；追加原件时固定到当前资料 | 原件保存后自动创建解析任务；PDF 保留原件并如实报告不支持解析；失败／未知结果保留文件和原幂等请求 | 空文件、非法名称、8 MiB 边界、多文件部分成功、失败重试、未知结果确认、追加版本；正文不变 |
| F10.02 解析与恢复 | 清单和详情显示等待、执行、成功、部分识别、失败、不支持、取消与未知 | 取消以服务端响应为准；失败保留原件；重试使用同一原件与原命令；旧响应不能重新激活已取消任务 | 轮询、取消、迟到响应、重试、状态读取失败；行、详情和任务中心状态一致 |

| F10.05 整理、关联与移除 | 重命名、改分类、解除项目关联、移出目录、恢复；操作后可撤销 | 原件和历史不删除；不可用对象不能用于新绑定，旧绑定继续可追溯；CAS 冲突先读取最新资料 | 各命令请求字段、撤销、409／未知结果、显示已移出、跨分类列表重排 |
| F10.06 助手资料范围 | 文献详情加入／移出助手上下文，再前往写作 | 按服务实例和项目固定文献条目版本；真正运行前仍由学生在助手上下文中确认 | 单篇、多篇、10 篇上限、移除后同步、项目隔离；不串用其他项目或未选资料 |
| F11.01—F11.04 模板与绑定 | 模板清单选择对象；查看结构、格式值、范围、未知／冲突与来源；绑定／解除／撤销具体解析版本 | 项目绑定保存完整快照和 CAS；新解析不自动升级；绑定不修改正文 | 同名多模板、历史版本绑定、缺失／不可用版本、冲突后载入最新；已有要求集不被模板操作清空 |
| F12.01—F12.03 要求与来源 | 要求清单查看原文、范围、类型、参数、严格程度、可判定性与不确定性；选择版本并保存要求集 | 固定版本供写作、助手和评审共用；缺失、冲突、未识别保持可见；无有效版本时不能伪造绑定 | 多版本选择、空要求、来源定位、停用资料后的旧绑定、50 项上限、撤销和绑定历史 |

## 4. 真实动效映射

| 触发操作 | 状态变化与统一实现 | 退出安全与减弱模式 | 实测重点 |
| --- | --- | --- | --- |
| 上传表单、成功／错误通知 | `tp-swap` + `panelMotionHooks`；服务事实不等待动画 | 离场立即 `inert`；收起不等于服务端取消；减弱为不超过 120ms 的淡入淡出 | 连续打开／收起、上传中收起、部分成功与失败重试 |
| 文件入队、移除、资料分类／筛选／恢复 | `TransitionGroup tp-list`，文件临时 UUID、资料 ID 为稳定 key，`listMotionHooks` 保留离场几何 | 数据立即更新；离场不可点击；减弱无位移和重排等待 | 新增、删除、筛选、移除／撤销、长文件名下布局稳定 |
| 选择资料／文献、切换解析版本 | 详情 `tp-swap`，按对象／版本 key 替换；项目与请求身份继续校验 | 快速切换不接收旧响应；减弱只淡入淡出 | 连续选择、加载、读取失败、历史版本不串稿 |
| 窄屏打开／关闭详情 | 既有 `TpDrawer` 的 `tp-drawer`；选择后立即打开，关闭返回清单触发项 | 抽屉关闭不取消服务端任务；焦点不进入离场内容；减弱只保留短淡入淡出 | 390px、Esc、遮罩、焦点陷阱、快速重开、长标题 |
| 分类、文献来源及自定义控件浮层 | 既有 `TpSelect` 的 `tp-pop`，保持主题和禁用语义 | Esc 先关闭控件浮层；禁用项不可选；减弱无位移／缩放 | 键盘方向键、Enter、Esc、390px 边界、四主题 |
| 展开版本、绑定历史、来源记录与诊断 | 共享 disclosure／`tp-swap`；完整事实保留在展开区域 | 减弱不隐藏文字；高度／透明度不超过共享时长 | Enter／Space、长诊断、完整 SHA-256、快速展开收起 |
| 解析／检索状态推进、取消和重试 | 状态与结果 `tp-swap`，列表按稳定 ID 更新；进度保持不确定指示，不伪造百分比 | 终态不倒退；取消结果以服务端为准；减弱保留状态文字与实时标记 | 排队→执行→终态、轮询失败、取消、幂等重试 |

所有动画读取现有语义令牌和共享过渡，不在页面新增平行动画系统，也不为动画延迟上传、绑定、保存、取消或恢复。
