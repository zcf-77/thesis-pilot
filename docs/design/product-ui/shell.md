## 文案与层级

- 正式页面不再显示展台页脚口号，正文与当前任务占据视觉主角。
- 项目切换标签收敛为“当前项目”；搜索标题收敛为“搜索工作区”，输入框本身承载范围提示。
- 阶段弹层删除重复的航线教育性说明，保留异常原因、完成条件与下一步。
- 搜索补齐今日、评审、收件箱、导出备份，使十二个正式页面都可从指令面板到达。

仅使用现有 `--tp-*` 令牌、Vue/daisyUI 组件和共享过渡。正式内容底部留白由 112px 收敛到 48px，写作页为 24px；窄屏顶栏不再以多行粘性区域遮挡正文。实际浏览器结果在统一验收后补记，未执行不计通过。
