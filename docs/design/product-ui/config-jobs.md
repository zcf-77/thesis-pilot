# 配置台、流程与执行任务：产品级界面设计

日期：2026-11-19。施工单：W-E；基线：`923336a`。范围为正式工作区配置、流程、提醒参数、配置运行记录和任务中心，不包含共享组件、服务契约或后端改造。

## 1. 设计目标与取舍

- 默认首屏回答三个问题：管理哪个对象、当前是否可用、下一步做什么。配置名称、固定版本、关联状态和主操作优先；说明、内部 ID、原始诊断与完整快照按需展开。
- 采用紧凑的数据列表与分区表单。四库和任务使用稳定的双栏“目录／详情”，流程使用“流程目录／阶段编辑”；不在纸面面板里继续套说明卡、统计卡或结果卡。
- 保存、复制、启停、取消与重试继续调用现有服务。配置编辑产生不可变新版本；试跑和重试固定输入及配置；取消只接受服务端确认，不显示虚构百分比或本地完成态。
- 凭据只展示服务器是否已配置，不显示凭据别名、密钥或可供复制的凭据字段。任务普通视图仅显示范围、版本和必要结果摘要，技术快照保持折叠。

## 3. 页面结构与精简文案

### 配置台

- 页头只保留「配置台」；模块标签为智能体、提示词、模型、AI 接口、阶段流程、运行记录、提醒参数，不保留宣传性眉题、副标题和无意义启用统计。
- 四库目录行显示长名称、当前版本、启停／关联状态和一句配置说明；搜索与状态筛选放在目录内部，新增是当前区域唯一主按钮。
- 详情首区显示名称、当前版本、关联状态及编辑／复制／启停。关联链用连续文本节点和箭头，不用嵌套卡片；失效节点同时有文字原因。
- 所选历史版本与当前版本明确分写。只读内容、版本比较、引用和试跑均为有标题的分区；原始标识、长 JSON 和完整运行快照折叠。

### 流程

- 目录行直接呈现流程名、当前版本、阶段数和启停状态；编辑器标题写「基于 vN 编辑」，保存按钮写「保存新版本」。
- 阶段按稳定 ID 排列，上移／下移／移除均为实际动作；每个阶段是一条带序号的分区，不再使用底板卡套卡。
- 历史入口保留「查看流程历史」，展开后选择只读版本；历史查看不修改编辑草稿、项目绑定或当前启停状态。

### 执行任务

- 页头只保留「执行任务」和真实活跃计数。筛选、刷新与列表／详情构成主工作区。
- 列表行显示任务类型、状态、固定输入摘要、创建时间、失败原因和唯一下一步；内部 ID 不在目录露出。
- 详情先给状态与可执行动作，再给输入范围、产物摘要和来源链接；配置快照、固定输入、错误码与任务 ID 放入技术详情。所有支持的任务类型进入类型筛选，不再只列四类。

## 4. 动效映射

| 真实触发 | 状态变化与实现 | 减弱模式 | 验收 |
| --- | --- | --- | --- |
| 切换配置库、流程、运行记录、提醒参数 | 模块内容 `tp-swap`，标签指示器沿用共享过渡 | 不超过 120ms 的透明度变化 | 方向键与点击切换；旧请求取消，不覆盖新模块 |
| 搜索、状态／类型筛选、分页 | 配置、流程、运行和任务集合使用稳定业务 ID 的 `TransitionGroup tp-list`；详情使用 `tp-swap` | 仅淡入淡出，无位移和交错 | 清除筛选恢复列表；离场元素 inert；选中详情不串项 |
| 新增／编辑／复制配置，新建／编辑流程 | 表单 `tp-swap`；服务确认后立即更新事实，不等动画 | 保留完整表单与错误，只有短淡入淡出 | Esc 取消；退出期间禁止交互；未提交输入不会因特效被重放 |
| 展开历史、快照、诊断和固定输入 | 局部 `tp-swap` 或语义 disclosure；浮层继续使用 `TpSelect` 的 `tp-pop` | 不做缩放或位移 | 键盘可展开／收起；Esc 先关闭下拉，不丢弃外层草稿 |
| 试跑创建、状态刷新、结果出现 | 状态与结果使用 `tp-swap`；任务列表使用 `tp-list`；运行结果只在服务端产物校验通过后展示 | 保留状态文本，不运行装饰性进度 | 取消结果以服务端为准；重试生成新记录；旧结果不回写 |

## 5. 边界与可执行检查

- **390px：**目录与详情转单栏；筛选和动作允许换行；长配置名、长模型名、错误文本与快照可断行；页面无横向溢出，紧凑点击目标不小于 28×28。
- **键盘：**目录按钮、标签、下拉、表单、详情和任务链接均可到达；TpSelect 支持方向键、Enter、Esc；编辑区 Esc 取消，复制区 Esc 只取消复制；详情容器可用程序焦点但不进入多余 Tab 顺序。
- **禁用／错误：**保存、启停、试跑、取消和重试在请求期间有明确禁用或 loading；错误不自动消失，原数据与草稿保留；部分关联读取失败不得当作全部无效。
- **四主题：**只消费现有 `--tp-*` 语义令牌与 Tp* 组件，依次检查朱墨、荧光笔记、夜航、晨雾；状态始终带文字，不只靠颜色。
- **服务行为：**沿用现有 aiConfigs、projectFlows、reminderSettings 和 jobs 接口，不修改 DTO 或 Mock／HTTP 适配。产品 AC-010／016／017 的完整场景仍由正式验收判定，本轮界面回归不冒称整项 AC 已通过。
