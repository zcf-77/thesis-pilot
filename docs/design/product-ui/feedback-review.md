# 反馈与评审：功能及动效映射

日期：2026-11-19。施工单：W-E。基线：`923336a`。

## 1. 来源、范围与保护边界

- 来源：F09、F14，AC-004、AC-018，关联 AC-003、AC-010；遵循 `DESIGN-SPEC`、`page-functional-design.md` 与 `global-motion-implementation.md`。
- 范围：正式工作区反馈页与评审页、其页面级组件和展示辅助函数。保留既有 HTTP/Mock 同契约服务、真实后台任务、幂等命令、CAS 版本检查、取消/重试、轮询与迟到响应防护，不改共享组件、服务或后端。
- 反馈路径固定为“原文 → 拆解建议 → 学生纠正与关联 → 学生处理 → 历史”。导师原文不可变；AI 建议采纳前不成为正式解释项；学生已处理不等于导师认可，也不修改正文或任务完成状态。
- 评审路径固定为“范围与固定输入 → 执行任务 → 报告 → 历史/下载”。报告包含问题、位置、依据、修改方向、分项参考分、未检查项与局限；仅评审不修改正文、正式计划、任务状态或导师认可状态。
- 本轮完成只指页面呈现、既有真实交互和相应工程回归，不据此宣告 AC-004、AC-018 或全部产品场景验收通过。

## 2. 统一呈现决定

1. 页头只保留页面名称、一句工作说明和当前主动作；删除中英文宣传眉题、重复口号与大块统计卡。数量与当前正文版本改为轻量事实文字。
2. 反馈首屏按阅读顺序排列：左侧意见索引，右侧完整原文、真实拆解、选中解释的处理区。原文用墨；待决定拆解用铅笔；歧义、未核对、取消用留白；旧证据和旧报告用旧稿；只有学生采纳/处理决定使用印章。
3. 原文始终逐字显示并保留换行。选中解释后由原文高亮表达对应关系，阅读态不再重复粘贴同一段原文；编辑态仍保留精确选区供核对。UTF-16 偏移、解释版本和运行配置进入详情。
4. 拆解建议逐项展示原文范围、解释、建议任务与状态；保留单项采纳、修改后采纳、拒绝、撤销和批量采纳。每条建议自己的决定记录按需展开，不与解释项处理历史混为一份。
5. 反馈处理区把理解、任务、修改证据、处理说明和处理动作串成一条路径；去掉重复眉题、重复印章与“关联不会改变……”等教育性复述。缺证据、未明确、未核对和证据过期在处理动作前说明真实阻碍。
6. 评审首层按“新建/固定输入 → 当前任务 → 选中报告”组织。历史列表用于选择，不与报告争夺视觉主角。失败、取消和进行中只保留一个任务状态区，不在横幅与空态里重复。
7. 报告合并为一张连续稿面：范围与摘要、分项参考分、问题清单、量表与局限、详情与执行追溯。技术 ID、请求/响应模型、尝试次数和任务链接放入按需详情；HTML 与 Markdown 下载继续对应所选报告。
8. 仅使用既有 `--tp-*` 令牌、Tp 控件、共享材质和过渡，不新增颜色或平行动画。390px 下双栏转为单栏，长原文、长解释、长依据和模型名允许换行，页面不得横向溢出。

## 5. 真实动效映射

| 触发操作 | 状态变化与共享实现 | 退出安全与减弱模式 | 实测重点 |
| --- | --- | --- | --- |
| 打开/取消反馈录入，开始/取消解释、任务、证据编辑 | `tp-swap` + `panelMotionHooks`；草稿和业务提交不等待动画 | 离场立即 `inert`；Esc 焦点回录入按钮；减弱 100ms 淡入淡出 | 连续打开/取消、输入法组合键、请求中状态与草稿 |
| 保存反馈、采纳/撤销建议、筛选意见 | 意见与建议用稳定业务 ID 的 `TransitionGroup tp-list` + `listMotionHooks` | 数据先生效；离场不可点击；快速重读不接受旧响应；减弱无位移/缩放/重排等待 | 新增、批量决定、撤销、筛选进出及长文本尺寸 |
| 选择反馈、查看解释/证据摘录、展开建议决定与处理历史 | 详情和错误用 `tp-swap`；历史用语义 `details` 与共享 disclosure 过渡 | 切换取消旧详情请求；普通阅读不重复钤印；减弱只保留 100ms 透明度 | 快速切换、历史加载失败、键盘 summary、原文选区不丢 |
| 开始/取消/重试拆解，学生处理/撤销 | 任务状态 `tp-swap`；仅学生决定使用既有 `TpSeal` 动效 | 服务端回执决定状态；取消后迟到结果不落库；减弱印章为 100ms 淡入 | 状态不倒退、重复命令、只播放一次、导师认可文案不存在 |
| 打开/取消新建评审，切换范围、量表、智能体 | 表单与局部输入事实 `tp-swap`；选择立即更新，未提交不改业务 | 关闭不取消既有评审；减弱无位移；焦点保持可用 | Esc、键盘自定义 Select、无正文/无智能体与连续变更 |
| 新建/取消/重试评审、轮询推进、搜索历史 | 历史稳定 review ID 的 `tp-list`；唯一任务状态区 `tp-swap` | 不伪造进度；轮询响应不倒退；离场不可操作；减弱仅 100ms 淡入淡出 | 新记录、终态、重试、筛选、取消与迟到响应 |
| 切换报告、筛选问题、展开量表/技术详情、下载反馈 | 报告 `tp-swap`，问题 `tp-list`，语义 `details`；分项沿用既有数字/圆环组件 | 旧报告请求不能覆盖新选择；下载状态不阻塞阅读；减弱保留所有未知项和分数 | 快速切换、报告读取失败、两格式下载、旧稿定位与 390px |

所有页面动画沿用共享令牌；系统和手动减弱模式均不超过 120ms（当前共享实现为 100ms）。不得为了动画延迟保存、取消、采纳、处理、评审创建或下载。

## 6. 实施与验收记录

### 已实现

- 反馈页收敛为意见索引与连续阅读稿面；完整原文只保留一个主阅读实例，解释阅读态不再重复原文摘录，精确范围与解释版本进入“解释详情”。
- 真实拆解继续固定原文和内容助手版本，保留取消、按原输入重试、逐项/批量采纳、修改后采纳、拒绝及撤销；新增每条建议的决定记录和拆解执行详情。
- 理解纠正、已有/新建任务、正文/资料证据、旧证据复核、学生处理/撤销与处理历史均保留；阅读区只有学生处理决定使用一次印章，继续明示“不代表导师已认可”。
- 评审页删除宣传式概览和重复状态空态；固定范围/版本、唯一任务状态、连续报告、历史搜索、参考分、未检查项、问题定位、两种下载及执行追溯均保留。模型和技术 ID 进入详情。
- 实际浏览器发现并修复：评审表单打开后焦点此前仍留在页头，Esc 无法收起；现在打开后聚焦首个控件，Esc 返回“新建评审”按钮。
- 新增 `tests/unit/product-ui-feedback-review.test.ts` 与 `tests/e2e/product-ui-feedback-review.mjs`。后者使用同契约 Mock 和固定成功报告夹具，只作隔离视觉/交互回归，不代表真实模型成功。

### 未关闭缺口

- `vp check` 的 lint 阶段多次在分析前发生 Node 原生 `ArrayBuffer` 分配 OOM（exit 134），提高 `NODE_OPTIONS` 后仍可复现；不能登记 lint 通过。完整检查还遇到过并行代理文件的格式差异，本轮未修改该文件。
