# 计划页产品级改造：功能、状态与动效设计

日期：2026-11-19。施工单：W-E；基线：`923336a`。范围仅为正式工作区 `WorkspaceTasks.vue` 与 `workspace/tasks/**`，不重做旧设计展台。

## 1. 来源、目标与边界

- 需求：F03 的阶段位置、当前要求与学生确认派生进度；F07 的任务目标、验收条件、期限、依赖、章节、具体版本证据、排序、状态、返工、个人规划、AI 调整候选与计划版本。
- 验收关联：AC-003（证据与复核）、AC-009（计划候选、约束与取消）、AC-016（有/无个人规划、派生进度及计划不被隐式修改）。
- 已有真实能力：任务 CRUD 中的新增/编辑/排序、确定性草稿校验、服务端依赖/日期/硬截止校验、证据版本关联与历史、学生确认/返工/重开、个人规划、真实计划候选生命周期、采纳/保留/撤销及不可变计划历史。
- 本轮目标：以“任务清单 → 当前任务详情/决定”为主工作流；首屏直接呈现目标、期限、状态、前置与证据缺口、下一步操作。阶段仍可见；时间线、个人规划、历史和技术信息按任务上下文或按需展开。
- 不变约束：AI 只产生铅笔候选；学生印章决定才改变完成状态或正式计划。不得自动确认、不得移动硬截止、不得把 AI 输出写成事实；保存、采纳与撤销立即发命令，不等待动画。
- 排除：不新增后端字段、共享组件、占位入口或任意历史快照一键恢复。缺少的服务能力如实保留错误与恢复路径，不用视觉改造冒充新业务。

## 2. 信息架构与统一呈现

1. 页头仅保留“计划与进度”、由有效确认派生的紧凑进度，以及唯一主行动“新增任务”；删除英文眉题、宣传式副标题与重复统计说明。
2. 阶段条保留当前阶段、绑定流程和项目设置入口；不再以营销文案重复页面标题。
3. 桌面主区左列为任务清单和 AI 调整候选，右列为选中任务详情及该任务历史。详情承担验收条件、依赖、证据、确认、返工和排序，清单不复制整份详情。
4. 任务清单每行显示任务目标、预计/硬截止、状态、前置数量或未就绪、缺失/待复核证据，以及唯一下一步动作。行选择与行内动作分离；集合使用任务 UUID 作为稳定 key。
5. 时间线置于主工作流之后，保留当前/候选双条、硬截止和任意日期窗口；个人规划与计划历史作为辅助设置和记录，不再抢占首屏。
6. 任务版本、计划版本和模型/配置等标识只在影响版本判断的位置显示，或进入“依据与来源”/历史详情。密集区域使用分隔线、对齐、字阶与留白，不增加层层卡片。
7. 仅消费现有 `--tp-*` 语义令牌；390px 下主区单列，行内动作换行而非压缩文字，时间轴只在自身容器横向滚动。

| F07 依赖与期限 | 编辑器前置复选、自定义日期控件；详情依赖链接 | 新增/解除前置，修改起止和硬截止；点击依赖切换任务 | 合法关系进入正式任务；循环、自身/缺失/归档依赖、日期倒置、超项目/任务硬截止由服务端拒绝并保留输入 | 项目截止和任务依赖被计划候选共同读取 | 非法图或日期无任何任务变化；冲突文案可定位到任务，修正后可重试 |

## 4. 状态覆盖自查

| 状态 | 页面行为 |
| --- | --- |
| 首次空白 | 清单给“新增第一项任务”；时间线、个人规划和候选不虚构任务或效率。 |
| 筛选无结果 | “未完成”无结果时可切到全部；正式数据保持不动。 |
| 加载 / 部分完成 | 列表保留稳定骨架/读取状态；详情逐项限流补读，部分失败保留其他任务并提示后续可能不全。 |
| 失败 | 列表、详情、反馈关联、流程、计划、历史、证据来源分别给重试；已有数据与原计划不清空。 |
| 取消 | 编辑 Esc 不保存；规划 Esc 不改项目；候选取消只取消生成；离场请求 Abort，迟到响应不回写。 |
| 过期 / 冲突 | 候选按基础计划过期；任务/规划按版本冲突；输入保留，由学生选择载入最新版或重新生成。 |
| 未知 | 无响应、5xx、无效响应不猜结果；保留命令并用相同命令 ID 确认，禁止产生重复决定。 |
| 归档 / 不可用 | 归档任务保留历史与依赖；状态/确认先要求恢复；被阻止候选不可勾选。 |

## 5. 真实动效与减弱模式映射

| 触发操作 | 状态变化与正式数据时机 | 动效 | 减弱模式（≤120ms） | 实测点 |
| --- | --- | --- | --- | --- |
| 新增/编辑任务打开、取消、保存回执 | 打开只切界面；保存命令立即发送；成功回执后才关闭编辑器 | 编辑器与详情同位 `tp-swap`；错误同位淡入 | `transform:none`，100ms 透明度；不等待数据 | Enter 保存、Esc 取消、快速重开、焦点返回 |
| 新增、筛选、排序、归档后清单变化 | 以服务端回执/重读结果更新数组 | `TransitionGroup tp-list`，key 为任务 UUID，复用 `listMotionHooks` | 100ms 淡入淡出，取消位移和 move | 实际新增、筛选、上下移；退出元素不可交互 |
| 切换任务/候选状态 | 选择立即变化；读取只替换对应内容 | 详情、读取、错误、候选内容 `tp-swap` | 100ms 透明度，不位移 | 快速选择不串详情；取消/失败不闪现 |
| 生成调整候选 | 先创建队列命令，轮询只读候选；不写正式计划 | 铅笔材质、内容 `tp-swap`、候选条目 `tp-list` | 100ms 透明度；流动虚线之外的位移取消 | 生成、取消、失败、迟到响应 |
| 勾选并采纳/保留/撤销 | 点击即发送决定命令；回执后更新计划与任务 | 采纳出现学生印章与墨态；条目和动作 `tp-swap/tp-list` | 印章仅 100ms 淡入，无缩放/回弹 | 仅采纳播放一次印章；保留/拒绝不用危险色 |
| 时间窗切换、候选日期预览 | 只改变派生视图；候选不替换当前任务 | 当前/候选条位置与宽度过渡，稳定任务行 `tp-list` | 位置/宽高不平滑移动，仅 ≤100ms 透明度 | 前两周/后两周、生成与采纳后候选条消失 |
| 展开任务/计划历史、依据 | 只改变可见性，读取失败可重试 | 既有 disclosure / `tp-swap`；历史项稳定版本 key | 100ms 透明度过渡，信息不减少 | 键盘 Enter/Space 展开，Esc 不误改业务 |
| 个人规划编辑 | 保存立即调用项目版本更新 | 表单与说明 `tp-swap`；错误不抖动 | 100ms 淡入淡出 | Esc 焦点返回；Ctrl/Cmd+Enter 保存 |

- 浏览器实测：使用本机 Chrome 运行独立 `product-ui-plan.config.ts`，3 项集成用例全部通过。正式 Vue 页面通过真实 HTTP 客户端与 DTO 校验读取合成响应；不是静态截图或跳过校验的组件替身。
