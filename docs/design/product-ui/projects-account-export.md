日期：2026-11-19。施工单：W-E。基线：`923336a`。

## 1. 来源、范围与边界

- 来源：F01、F02、F20，AC-001、AC-011、AC-012、AC-016，以及 `DESIGN-SPEC`、`page-functional-design.md`、`global-motion-implementation.md`。
- 范围：正式工作区的项目目录、首次设置、项目设置、账户与偏好、正文／修改说明导出、完整项目备份与恢复。
- 保留既有真实服务、幂等键、CAS 版本检查、请求取消、轮询和迟到响应防护；本轮只调整页面层级、控件组织、文案和对应回归，不改共享外壳、共享组件、服务或后端。
- 评审报告仍在评审页按所选报告真实下载；本页只提供明确去向，不复制一套报告状态。账号验证、密码找回、权限分配及真实认证管理不在范围内，不新增入口。
- “完成”仅指本轮页面与工程检查；不据此宣告 AC-001、AC-011、AC-012、AC-016 的完整产品场景已经验收。

## 2. 统一呈现决定

1. 页头只保留对象名称和一句当前工作说明，删除中英文宣传式眉题与重复帮助。
2. 项目首层依次呈现项目名、论文题目、当前状态／阶段、截止和正文状态；流程版本、规划全文、已有产物及更新事实进入“项目详情”。长题目与长规划均允许换行，不以截断冒充完整事实。
3. 项目编辑与首次设置沿用原地形表单。普通可逆归档直接执行并提供撤销；恢复保留原对象，不制造副本。设置冲突保留输入，由用户选择重新读取后再核对。
4. 账户按“个人资料—通知—外观—会话”分组。名称与通知共用既有原子保存和冲突恢复；外观即时生效。补齐 `show_deferred` 对应的“在待留意中显示已延后建议”，并说明无论开关状态都可到“已延后”分类查看。
5. 导出页先选固定版本和格式，再执行；最新任务紧邻对应表单，完整历史独立保留。Word／PDF 的原件保留、正文重建、修订标记、损失及告警不隐藏；失败说明原稿安全和下一步。
6. 备份与恢复是两条决定路径。备份明确包含范围；恢复选择 ZIP 后仍只创建独立项目，损坏／篡改／超限／失败均不覆盖原项目。只有实际服务端任务完成才显示可下载，浏览器点击下载不伪称已确认写入磁盘。

## 4. 真实动效映射

| 触发操作 | 状态变化与统一实现 | 退出安全与减弱模式 | 实测重点 |
|---|---|---|---|
| 打开／切换首次设置步骤、项目设置 | `tp-swap` + `panelMotionHooks`；业务草稿不等待动画 | 离场立即 `inert`；快速返回不被旧请求改写；减弱为 100ms 淡入淡出 | 连续上一步／下一步、Esc、请求中关闭；最终焦点与输入值 |
| 新建、归档、恢复、撤销、切换项目范围 | 项目卡 `TransitionGroup tp-list`，项目 ID 为 key，`listMotionHooks` 冻结多列离场几何 | 数据立即更新；离场不可点击；减弱无位移／缩放／重排等待 | 卡片实际进入／离场、归档撤回归位、长题目下尺寸稳定 |
| 展开项目详情、已有产物、导出说明 | 原生 `details` + 共享 disclosure 过渡；事实全文保留 | 减弱只保留不超过 100ms 的透明度过渡；键盘 summary 可操作 | Enter／Space 展开收起、长文本、390px 不溢出 |
| 保存设置／偏好、读取及冲突反馈 | 错误、成功和冲突区域 `tp-swap`；失败不自动消失 | 新操作替换旧提示；减弱仅透明度；不以抖动代替错误文字 | 连续失败／重试、竞争更新、两种冲突决定及焦点 |
| 切换主题与减少动效 | 使用既有外观 store 与主题过渡；业务组件不重建 | 减弱时不做主题揭示；账户输入和会话不变 | 四主题及系统／手动减弱；运行任务继续可辨 |
| 选正文格式、Office 原件状态、修订标记 | `tp-swap` 替换对应选项和说明；不触发导出任务 | 快速换版本只接受最新原件响应；减弱无位移 | 连续换版本／格式、加载／无原件／失败、复选键盘 |
| 新建导出／备份、状态推进、取消／重试 | 记录使用稳定 job ID 的 `tp-list`；状态与最新结果 `tp-swap` | 退出中的按钮不可操作；取消以服务端响应为准；减弱保留状态文字与实时圆点 | 实际新增、轮询、终态、防旧响应回退、快速重复点击 |
| 选择／清除备份、显示恢复结果 | 文件动作与恢复面板 `tp-swap`；恢复 job ID 与状态决定内容 | 清除只清选择，不取消已接受任务；取消后迟到结果不跳转；减弱 100ms | 连续选择坏／好文件、恢复中取消、完成只跳转一次 |

所有动画读取现有语义时长与曲线；不在页面新增平行动画系统。页面不为了动画延迟保存、归档、导出、备份或恢复。
