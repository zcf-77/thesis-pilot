# W-E 内容助手、专业副驾与候选审阅

范围：`apps/web/src/workspace/writing-assistant/**`、`apps/web/src/workspace/assistant/**`。本轮重排正式界面与恢复交互，不修改写作核心、共享组件、服务契约或后端。当前 `AssistantSessionCreate.role` / `AssistantRunCreate.purpose` 仅支持 `content` / `content_revision`；格式与引用继续使用既有独立专业面板，不增加无真实契约的综合或五专业会话入口。

### 状态与恢复核对

- 空白：无会话时只保留名称输入和创建动作；无消息时提示从选区与修改目标开始；无候选时提供回到对话的明确入口。
- 加载：保留已有消息、候选和操作外壳；首次读取显示简短状态，不用空白闪烁代替旧内容。
- 失败：原文、草稿与候选保持；可重试读取或运行；写操作结果未知时只能确认原命令，不能另发新命令。
- 部分完成：当前单步内容运行没有可拆分的真实子任务，不伪造部分进度；目录、消息、运行任一读取失败分别汇总实际失败，成功数据继续显示。
- 取消：取消以服务端响应为准；活跃入口保持稳定；取消/放弃与失败、拒绝使用不同语义。
- 过期/冲突：旧版本与未保存状态禁用写入；重新选择当前正文后继续；编辑会话冲突保留名称输入并载入最新版本。
- 未知：无法解析的旧结构、未支持的检查和损坏草稿明确说明，不显示默认通过或自动发送。

## 2. 信息层级与统一呈现

1. 副驾首屏依次是当前会话、当前对话/运行、需要审阅的候选、输入；不再重复展示功能自述。
2. 当前选区、正文版本、资料/文献数量和上下文核对状态合并为一条摘要；完整配置、绑定和来源 ID 仅在固定上下文详情中出现。
3. 候选直接呈现目标、实际差异和逐项决定；检查通过只汇总，失败与不支持就地可见；运行错误显示用户可读原因，错误码进入详情。
4. 复用 `TpSelect`、`TpSegmented`、`TpStatus`、`TpButton`、`TpSeal`、`DiffText` 与 `AssistantComposer`；不增加原生下拉或另一套控件皮肤。
5. 副驾内容使用单一纸面，不再嵌套「会话卡 / 上下文卡 / 运行卡」。候选项和检查行保留必要材质边界；多面板容器只在外层分隔会话。
6. 390px 下副驾由既有抽屉承载，内部控件换行、长文任意位置断行、消息区独立滚动；不引入页面横向溢出。键盘焦点、选中态和状态文案不依赖颜色。

## 3. 动效映射

| 触发操作 | 状态变化 | 对应动效 | 减弱模式 | 实测证据 |
| --- | --- | --- | --- | --- |
| 切换对话/审阅、展开或取消新建、打开上下文/运行详情 | 同位内容替换，业务数据立即更新 | `Transition tp-swap` + `panelMotionHooks`，退出期间 `inert` | 共享 100ms 淡入淡出，无位移 | 浏览器实际操作切换并读取运行动画；快速反向操作后最终视图与焦点正确 |
| 新消息、新候选、打开/收起独立会话、资料锚点增删 | 稳定业务 ID 的集合变化 | `TransitionGroup tp-list` + `listMotionHooks` | 共享 100ms 淡入淡出，取消移动与重排 | 新对象只进入一次；退出对象不响应交互；旧请求不能重复插入 |
| 接受/拒绝/改回待定、采纳/放弃/撤销 | 服务端决定和候选状态更新 | 候选状态过渡；仅采纳使用 `TpSeal` 钤印 | 钤印改为 100ms 淡入，无缩放/旋转 | 真实服务命令返回后才显示结果；动效不推迟写入 |
| 排队、执行、失败、取消、重试 | 同一运行状态区更新 | `tp-swap` 与 `TpStatus live`；无进度条、无计时模拟 | 保留真实状态，涟漪之外无环境动画 | 活跃/终态切换不闪空；取消后旧 running 响应不恢复活跃 |
| 读取更早消息、新回复到达、切换会话 | 阅读位置保持或明确回到底部 | 不使用滚动动画；只在新内容提示上使用 `tp-swap` | 同样无滚动动画 | 已在底部的会话跟随新回复；翻阅旧消息时不被拉走；重新打开恢复各自位置 |

## 4. 本轮边界与精确缺口

- 不新增真实模型、综合编排或五专业运行；当前正式会话 DTO 只接受内容角色。要完成 SG-08B，需后端扩展角色/目的、各专业固定输入与产物契约，再由对应专业面板接入；本轮不以改名或静态入口冒充。
- 写作共享外壳当前只实例化一个 `activeDefinition`，单个副驾宽度为 320—480px。`WorkspaceAssistantPane` 保留并优化最多两个独立内容会话面板；若要求在同一写作页并排两个副驾，需要共享外壳提供第二面板轨道/焦点与窄屏策略，不在本子任务中复制编辑器或强行覆盖正文。
- 候选回复中的修改理由来自助手消息，候选对象本身只有 `goal`、补丁和程序检查，没有独立结构化 reason 字段；界面不把目标或检查结果冒充模型理由。
- 本轮验收是前端功能、视觉和既有受控写入链的回归，不据此把 AC-005—008/010/015/019 整项标为产品验收通过。
