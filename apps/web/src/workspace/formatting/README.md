# SG-19 安全格式前端功能映射

范围：AC-005/006/011 的确定性格式纵切片，仅标题层级、对齐、字重及段落对齐；依据必须来自固定模板或要求解析版本，不调用模型，不导出 DOCX/PDF。

| 功能 | 入口、输入与决定 | 结果、关联与验收 |
| --- | --- | --- |
| 读取依据 | 正式写作台「安全格式」，读取固定正文、来源和项目绑定版本 | 展示来源解析版本、规则原文及锚点；无依据或未知对象明确不可生成 |
| 明确范围 | 选择一条规则，再手动勾选兼容的标题/段落 | 不默认全选；修改规则清空目标；规则与目标由服务端重新校验 |
| 候选审阅 | 生成候选，展示每项字段、原值、建议值与依据 | 逐项接受/拒绝，决定持久化，决定本身不改正文 |
| 采纳与撤销 | 仅采纳已接受项；通过命令撤销已采纳候选 | 使用服务端原子命令，完成后重新读取正式稿和来源保护；可在正式版本历史查看/恢复 |
| 过期与恢复 | 正文、绑定或来源版本变化使候选不可用 | 保留旧候选、提示重新检查；失败不伪报成功，未知命令结果通过命令查询恢复 |

空白、读取中、失败、无规则、无目标、部分决定、全部拒绝、过期、应用中和撤销均原位呈现。取消为关闭面板/放弃尚未提交的范围选择，不把关闭当作撤销服务器命令。跨项目切换销毁面板并中止旧读取，旧响应不覆盖新状态。

动效：展开面板→共享 tp-swap；候选/错误/命令结果→共享 tp-swap；候选列表→稳定 candidate ID，逐项决定原位更新。沿用共享减弱模式，无动画等待写入，不重建正文编辑器。

验证：专属 unit 验证范围过滤、旧候选阻止采纳及字段差异；编辑器/来源保护回归验证 null 段落属性、v1/v2兼容、受保护对象与普通格式事务拒绝。实际桌面 HTTP 路径由协调者录制验收，不以 unit 代替真实服务验收。
