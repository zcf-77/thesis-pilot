作品说明

毕设智途把论文进度、导师意见和正文版本放进同一个工作区，让学生能查到每项任务的依据，也能决定哪些修订写入正式稿。

用版本核对进度

为论文任务关联指定正文版本的选区，或指定资料的原件与解析位置。学生核对证据后确认完成。正文更新时，旧证据保留并可复核。

保留导师原话

保存导师反馈原文，选取具体段落，写下解释或疑问，再关联已有任务或创建新任务。学生可记录处理结果并撤销处理。

由学生决定修订

学生逐项审阅差异，决定接受、拒绝或暂留。服务端在采纳前重新检查正文版本、修改范围以及受保护的数字、引用和锁定对象。采纳后可撤销，也可从历史恢复。

技术实现与体验范围

Vue 与 Tiptap 提供写作界面，FastAPI 与 PostgreSQL 保存正文和不可变的版本历史，Redis 与 Celery 执行后台任务。当前演示可体验正式稿版本、带证据的任务、反馈处理、结构检查和安全格式。在线模型生成与正式 DOCX/PDF 导出仍待验收。
