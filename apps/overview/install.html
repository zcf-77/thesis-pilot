安装部署

在本机启动论文工作区与后台任务。

↓ 下载源码 ZIP

若浏览器未启动下载，请再次点击下载按钮。

📦准备环境并构建

使用 Linux 或 WSL 的 Bash，并以普通用户运行。安装 Node.js 26.13、Python 3.13、uv、PostgreSQL 16 和 Redis。解压源码 ZIP，在包含 apps 的目录中执行以下命令。 

export TP_REPO_ROOT="$PWD"
export TP_RUNTIME_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/thesis-pilot/runtime"
mkdir -p "$(dirname "$TP_RUNTIME_DIR")"

cd "$TP_REPO_ROOT/apps/web"
npm install --global vite-plus@1.6.0
vp install --frozen-lockfile
vp build --mode workspace

cd "$TP_REPO_ROOT/apps/api"
uv sync --locked
/usr/bin/python3 scripts/dev_services.py start \
  --runtime-dir "$TP_RUNTIME_DIR" \
  --postgres-bin /usr/lib/postgresql/16/bin --redis-bin /usr/bin

首次启动时 runtime 目录应尚未创建。PostgreSQL 和 Redis 的可执行文件路径随系统安装位置调整。

▶迁移并启动工作区

在同一终端继续执行。按提示输入自定的工作区口令，使用 32 至 256 个可打印 ASCII 字符。浏览器解锁时使用同一口令。

(
  set -e
  cd "$TP_REPO_ROOT/apps/api"
  set -a
  . "$TP_RUNTIME_DIR/api.env"
  set +a
  export TP_ENVIRONMENT=production TP_AUTH_MODE=workspace
  export TP_WORKSPACE_ORIGIN=http://127.0.0.1:8017
  export TP_WORKSPACE_WEB_ROOT="$TP_REPO_ROOT/apps/web/dist-workspace"
  read -rs -p '设置本机工作区口令: ' TP_WORKSPACE_ACCESS_KEY
  printf '\n'
  export TP_WORKSPACE_ACCESS_KEY

  uv run --locked alembic upgrade head
  uv run --locked celery -A thesis_pilot.workers.celery_app:app worker \
    --pool=prefork --concurrency=2 --loglevel=WARNING &
  worker_pid=$!
  uv run --locked python -m thesis_pilot.workers.dispatcher --poll-seconds 1 &
  dispatcher_pid=$!
  trap 'kill "$worker_pid" "$dispatcher_pid" 2>/dev/null || true' EXIT
  uv run --locked uvicorn thesis_pilot.main:create_app --factory \
    --host 127.0.0.1 --port 8017 --no-access-log
)

打开 http://127.0.0.1:8017/。可先查看 服务就绪状态，再新建合成项目，保存正文并运行一次结构检查。

概览可独立交给静态服务器或反向代理。将概览目录映射到 /overview/，让 /overview/source.zip 提供同目录的源码包。应用本机启动步骤使用回环地址。
