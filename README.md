## 三条产品主线

1. **证据驱动进度**：任务关联具体产物版本，AI 提出待核验项，用户确认状态。
2. **导师意见闭环**：保留反馈原文，拆为可审阅任务，关联章节与修改证据；学生处理不等于导师认可。
3. **受控局部修订**：限定选区和目标，保护数字、引用、公式及锁定文本，审阅差异后采纳，支持版本冲突检测与恢复。

## 当前可执行检查

仅需 Python 3 标准库，在仓库根目录执行：

```powershell
python -X utf8 scripts/validate_repository.py
git diff --check
```

第一条检查文档链接、要求和验收编号、官方快照完整性及必要文件；不检查产品功能，也不代表满足完整比赛要求。
